# Реестр архитектурных решений

Единый список действующих решений по устройству перестройки (24.11.2026; АР-24…АР-27 — после стенда и требования кросс-браузерности). Каждое решение — со ссылками на исходные отчёты Claude
(`docs/reports/audit_2026-11-24/`, ниже `C1` — этап 1, `C2B`, `C3`, `C4`) и DeepSeek (`docs/audit/architecture/`, ниже `DS`).
Исходные отчёты не правятся; при расхождении действует этот реестр, при расхождении реестра и плана — `rebuild/MASTER_PLAN.md`.
Изменение решения — новой строкой с датой и «заменяет АР-n», старая остаётся.

## Отклонено (с причиной)

| что | откуда | почему |
|---|---|---|
| навмеш во `Float32` / `Int16` | DS `RESOURCE_ARCHITECTURE` §8 | 11 317 из 22 267 чисел Ancient не представимы (C4 `evidence/navmesh_precision.txt`) |
| нативный вариант с переписыванием UI | DS `DEPLOYMENT_OPTIONS` D | не нужно: поток кадров (АР-08) |
| Tauri | C4 §4 | TS-логика оказалась бы без нативных ядер или на Rust |
| «граница WASM дорогая» как довод против ядра | DS §E | пустой вызов 3–7 нс (C4 `evidence/call_cost.json`) |
| «шаг не бит в бит → статистика 8 / 16 матчей» | C3 `MIGRATION_ROADMAP` §5 | требование владельца: только локализация (АР-06) |
| возврат к поведению после R0–R2 | C3 итог п. 12 | АР-21 |
