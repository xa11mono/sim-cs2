# Карта из 3D-геометрии игры (М148, владелец 20.10.2026) — начинаем с Mirage

Почему: стены у нас — обводка картинки радара (толстые линии, ±10–20 ед. на углах), окна, бортики, возвышения и прострелы
расставлены руками; разбор движка (`docs/reports/ENGINE_AUDIT.md`) — движок «не видит» 23 % (Mirage) / 41 % (Ancient) настоящих
убийств про. Подгонка стен под статистику (ветка `m140-vis`) — неверный путь (владелец: «стены сместились, боты будут ходить по стенам»).
Источник правды — геометрия столкновений из файла карты игры.

## Что уже есть (20.10)

- `tools/map3d/vpk_physics.py` — без сторонних библиотек: VPK v2 → `world_physics.vmdl_c` → KV3 v5 (zstd через системный libzstd) →

  «потолок / стены неба» (z 946–1024 над всей картой) выкинуты. Итог — `data/maps/mirage/geom3d/world_physics.npz` (единицы игры).
- Картинка: `docs/reports/map3d/mirage_meshes.png` — крыши, полы, проходы совпадают с радаром.
- Подписи мест от владельца: `data/maps/mirage/callouts/owner_callouts_1.png`, `owner_callouts_2.png`.
- Не разобрано: материал поверхности (прострелы) и группа столкновений (стена для пуль / невидимая стена только для игроков) — нужен
  разбор структуры KV3 (буфер 0); сущности карты (спавны, зоны закладки) — `de_mirage.vmap_c` / `.vents_c` (тоже KV3).

## Шаги (каждый — отдельный чат; картинки владельцу после каждого слоя)
1. **Проверка геометрии по демкам (главная цифра).** Луч «глаза убийцы → тело / голова жертвы» по треугольникам и блокам для всех
   убийств демок Mirage: доля «закрыто» должна быть около 0 (кроме прострелов). Где закрывает — точками и крупно: обычно это
   невидимые стены для игроков (playerclip) — их надо отделить. Обратная проверка — пары, которые не видели друг друга.
2. **Группы столкновений и материалы** — разбор KV3 (буфер 0): какие сетки / блоки — стены для пуль, какие — только для игроков; материал
   каждой поверхности (дерево, металл, камень…) для прострелов. Если разбор не дастся — playerclip по шагу 1, прострелы — по демкам.
3. **Слои карты из геометрии:** этажи пола (несколько на клетку), стены (геометрия выше глаз), укрытия с настоящим верхом, крыши,
   окна и проёмы (дыры в стенах), подъёмы (ступени, прыжок 64 / с приседом ≈ 66 ед., подсадка). Сетка видимости `VIS` — из этих слоёв
   (или прямой луч по геометрии). Ходьба — по навмешу из того же vpk (`maps/de_mirage.nav`). Стены радара — только для рисования.
4. **Сущности:** спавны T / CT, зоны закладки A / B — из сущностей карты (точно, не на глаз).
5. **Зоны и названия** — по подписям владельца: прямоугольники ровными квадратами (как на Simple Radar), пустоты между зонами
   заполнить ближайшими / своими названиями («подход к …»), названия — как у игроков.
6. **Подключить к игре и проверить:** разбор `tools/measure/engine/engine_audit.py vis` (доля «не видно» у убийств про → около 0,
   «видит сквозь стену» не растёт) + 8 матчей на карту по правилу прогонов; картинки владельцу. Потом — так же Ancient и новая карта.
