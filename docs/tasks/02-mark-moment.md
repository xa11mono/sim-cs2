# Задача 2: инструмент «Отметить момент» + перемотка

Мозг ботов не трогать. Это инструмент для владельца и Claude, чтобы замечания
были точными (матч, тик, состояние всех ботов), а не угадывались по фото.

## 1. Отметка
- Кнопка «Отметить момент» и клавиша **M**. Матч ставится на паузу.
- Симулятор сохраняет: номер матча, тик, время раунда, номер раунда, для всех
  ботов — позицию, взгляд, задачу (post.tag), причину взгляда, HP, оружие.
- Поле «что не так» (своими словами), выбор категории (Взгляд, Позиция,
  Команда, Гранаты, Закуп, Темп, Войс, Визуал — как разделы
  docs/PRINCIPLES.md), приоритет «срочно / обычно». Можно кликнуть по боту на
  радаре — «о ком речь» (необязательно).

## 2. Сохранение (с v397, М147 — без разбора нейросетью на странице)
- «Сохранить» (или Ctrl+Enter) — отметка сразу пишется в базу: текст, категория, приоритет, бот (если кликнут),
  сводка момента `state`, полный снимок игры (`snapAsset`), кадр радара вокруг бота (`frameAsset`), снимок всего
  экрана (`screenAsset`). Статус — «новое».
- Разбор — в чате Claude по снимку отметки (`tools/mark_open.js`, раздел 4). Карточка «Я понял так» (запрос к Claude со
  страницы, capability `sample`) убрана: владелец 20.10 — разбор на странице пишет глупо, не понимает, как двигаются игроки.
  Старые отметки с полем «понял» в списке показываются как были.

## 3. Список отметок
- Хранится в базе страницы (capability `db`, коллекция `marks`), не
  пропадает при перезагрузке. Поля: матч, тик, время, категория, приоритет,
  текст, номер пункта PRINCIPLES (ставит Claude при разборе в чате), статус, даты.
- Статусы: «новое» → «добавлено как Г6» → «исправлено в vNNN, проверь» →
  «подтверждено» (зачёркнуто). Кнопка «Подтверждаю» у статуса «проверь».
- Сверху новые и срочные. Клик по отметке — открывает момент из её снимка.
- Кнопка «Скопировать все» — текстом, на случай если нужно вставить в чат.

## 4. Перемотка и снимок отметки
- «Назад на 10 с» — быстрый пересчёт от ближайшего снимка в памяти.
- **«К отметке» (с v175) — из полного снимка, не пересчётом.** При нажатии
  «Отметить момент» снимается вся игра (все переменные симулятора: боты с
  позицией, взглядом, задачей, HP, оружием, деньгами; бомба, гранаты, смоки,
  огонь, время, знания команд). Снимок сохраняется файлом (asset, ~0,7–1,3 МБ),
  его id — поле `snapAsset` отметки. Открытие — `mkOpenSnap`. Отметки до v175
  снимка не имеют и точно не открываются.
- Claude открывает отметку так же: скачать файл (Artifact read, path =
  `snapAsset`) и `node tools/mark_open.js sim.html снимок.json "код"` (~2 с).
  Проверено: снимок → файл → открыть → доиграть 8000 тиков — бит в бит.
- Проверить: после перемотки картина ровно та же, что в момент отметки
  (сравнить сохранённое состояние ботов с пересчитанным, показать скриншоты).

## 5. Синхронизация (делает Claude в начале каждого чата)
- Прочитать новые подтверждённые отметки из базы страницы (ArtifactData).
- Внести в docs/PRINCIPLES.md: новый пункт (или дописать к существующему),
  дата, ссылка «матч N, тик T», пометка НОВОЕ, срочные — в раздел «Входящие»
  наверху. Записать номер пункта обратно в отметку.
- Подтверждённые владельцем в странице — зачеркнуть в PRINCIPLES.

## Готово, когда
Владелец отметил 2–3 момента в живом матче, увидел карточки «Я понял так»,
подтвердил; перемотка к отметке показывает тот же момент; после синхронизации
пункты появились в PRINCIPLES.md с номерами, а в странице — статус «добавлено
как …». Обновить docs, коммит и пуш.

## Что лежит в отметке сейчас (v385, 20.10.2026)
- снимок всей игры (`snapAsset`, открыть — `tools/mark_open.js`); кадр вокруг выбранного бота (`frameAsset`);
- **снимок всего экрана** как видел владелец — радар, табло, панели, войс (`screenAsset`; html2canvas с cdnjs, без сети — вид радара);
- сводка `state`: по каждому игроку — позиция, HP, оружие, куда смотрит и почему, кого видит, роль, задача места и её уровень,
  граната в задаче, гранаты, деньги, броня, **журнал решений за 15 с** (`log`, v384); **по каждой зоне**, где что-то есть, — кто
  стоит, сколько врагов там ждёт каждая команда по своему знанию, дым, огонь (`zones`).
