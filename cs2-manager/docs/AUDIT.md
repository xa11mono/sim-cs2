# CS2 Manager — архитектурный аудит (baseline v29)

Дата: 2026-10-30. Исходная версия зафиксирована коммитом `Baseline: CS2 Manager v29 as uploaded`.

## 1. Как устроено приложение

Чистые HTML/CSS/JS, ~30 `<script>` подряд. Каждый следующий слой (v15…v29) **оборачивает** глобальные
функции предыдущих (`window.X = wrap(X)`), поэтому порядок загрузки — часть архитектуры.

| Слой | Файл | Что делает | Публичные точки |
| --- | --- | --- | --- |
| Хранилище | `v29-storage-guard.js` | перехват `Storage.setItem`, ужатие при переполнении | `v29StorageUsage`, `v29CompactSaves` |
| Ядро | `auto_script_1.js` (312 КБ) | `teams`, `seasonState`, `transferState`, `currentTournament`, все форматы сеток, эфир, рейтинг, трансферы, экспорт/импорт | ~200 глобальных функций |
| Календарь | `v15…v20`, `v22` | игровые часы, автозапуск турниров, окно календаря | `v15AdvanceMinutes`, `skipGameCalendarDay`, `v22OpenCalendar` |
| Архив/хаб | `v25-hltv-hub.js` | архив сеток `cs2_hltv_archive_v1`, **старое** окно профиля команды, окно турнира, окно игрока | `hubArchive*`, `showHistory`, `hubOpenTournament`, `hubOpenPlayer` |
| Кубки | `v26-trophies.js` | SVG-кубки (12 архетипов), награды игроков `cs2_player_awards_v1` | `TW.*`, `twAwards*` |
| Составы | `v28-rosters.js` | уникальность ников, роли AWPer/IGL, стенд-ины | `repairRosters` |
| Параллельные | `v21`, `v22` | Tier-2/3 и академии: 44 события/сезон, свои сетки (single/double/swiss/gsl) | `seasonState.parallelSchedule` |
| HLTV-сайт | `v27-hltv-site.js` | полноэкранный **overlay** `#hs-root` поверх старого приложения | `hltvSiteOpen*` |
| Оболочка | `v27-ui.js` | шапка `#ui27-bar`, перекладка старых панелей в 3 колонки | `ui27Go` |
| Ядро v29 | `v29-core.js` | баланс, расписание 14 Tier-1, окна трансферов, шина событий `v29Emit` | `__v29Bus` |
| Новости | `v29-news.js` | лента `cs2_news_v1`, прогнозы/реакции `cs2_fan_v1` | `V29News` |

## 2. Каноническая модель данных

* `teams[]` — `name, pts, players[5] {nick, role, status, firepower, clutch, utility, tacticalIQ, age, form, morale, fatigue, country}`,
  `coach`, `history[] {tournament, season, place, delta, archiveId, isMajor, isElite}`, `isAcademy`, `seasonStartRank`.
* `seasonState` — `currentSeason, tournamentIndex, seasonSchedule[15], parallelSchedule[44], calendar.currentMs, hallOfFame, h2h`.
* `currentTournament` — живой объект сетки: `upperRounds/lowerRounds/grandFinal/bronzeMatch`, `swiss`, `gsl.groups`, `majorStages`, `bounty`, `broadcast`.
* Архив `hubArchiveExport()` — снимок по турниру: `{id, prestige, name, season, format, size, champion, blocks[{tab,title,standings?,sections[{title,rounds[{title,ms[{a,b,w,s,mp}]}]}]}], results[{n,p}], rost{team:[players]}}`.
* `transferState` — `history[]` (текстовый лог), `freeAgents[]`, `marketRuns`.
* `V29News` — `items[] {id, cat, title, lead, body[], tags[], imp, ts, season}`.
* `TW` — `p[nick] {mvp[], ti[], top[], aw[]}`.

## 3. Найденные проблемы

1. **Два интерфейса.** Старое приложение (боковая панель, рейтинг, панель управления, зал славы, архив) всегда видно; HLTV — overlay `position:fixed` с кнопкой «✕».
2. **Дубли.** Рейтинг: боковая таблица `#rating-table` + `pRanking` + топ-10 на главной HLTV. Профиль команды: модалка `#hltv-hub-backdrop` (`showHistory`) + страница `pTeam` + кнопка «Профиль команды» на ней, открывающая модалку поверх сайта. Игрок: `pPlayer` + `hubOpenPlayer` («Карточка игрока»). Зал славы: `#hall-of-fame` + `pAwards`. Архив турниров: `#tournament-archive` + `pEvents`.
3. **Сетки вне сайта.** Все `[data-event]` в HLTV вызывают `hubOpenTournament` (окно `.hl-overlay` поверх сайта). Кнопка «Смотреть сетку» на главной **закрывает** сайт. Живой параллельный турнир открывается модалкой `v21-parallel-modal`. Календарь — модалкой `v22OpenCalendar`.
4. **Главная HLTV** — три равные колонки по 7 блоков; нет иерархии, герой только при живом турнире.
5. **Трансферы.** В середине сезона рынок запускается с вероятностью 18% (`v29-core.js`), за одну проверку максимум 1 сделка, покупатель ≥2 окна между покупками. Замер (3 сезона, 44 команды): **1 / 10 / 10 / 8 переходов за сезон**, почти все — после Major. Нет подписаний свободных агентов, аренд, повышений из академий, продлений, переговоров; слухи не связаны с реальными переговорами.
6. **Новости.** Только итог турнира, апсет, смена №1, взлёт, кризис, трансфер/тренер/стенд-ин/пенсия, окно, превью Major, Tier-2. 9 категорий. За 3 сезона — 157 новостей, 45 уникальных «форм» заголовка. Матчевых новостей нет вовсе. Комментарии — 5–9 фраз на категорию. Лента рендерится одним блоком до 120 элементов без пагинации и поиска.
7. **Календарь.** Ровно 14 фиксированных Tier-1 (одни и те же названия каждый сезон), Tier-2/3/академии — 9 + 9 + 8 названий по кругу.
8. **Рейтинг игроков** назван «Рейтинг в духе HLTV 2.0» — это собственная формула по счёту карт и уровню игрока, а не HLTV Rating.
9. **Профиль игрока** не знает истории команд (только «текущий клуб»), нет трансферной истории. Истории очков рейтинга команды нет вообще — показывается только разница с началом сезона.
10. **Импорт сейва** без поля `news` оставляет новости предыдущего сейва (ссылки на чужие команды).
11. **Статистика** пересчитывается при каждом изменении составов (ключ кэша включает длину строки всех ников).
