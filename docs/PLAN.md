# План нового «мозга» ботов — согласован 01.10.2026 (шаг 1 «знание» — v169–170, шаг 2 «взгляд» — v171)

## Идея в двух строках
Сейчас бот действует по сотням правил «если X — делай Y», и правила спорят.
Будет так: **одна общая картина команды** → **несколько целей с весами** →
из них бот выбирает **где стоять, куда смотреть, что кинуть**.

## 1. Общая картина команды (одна на команду, обновляется каждый тик)
- **Враги:** для каждого — где может быть (вероятность по зонам), где и когда
  видели/слышали последний раз, насколько это свежо, с чем он (AWP, бомба).
  Основа уже есть — карта вероятностей по зонам; она становится единственной.
- **Давление:** сколько врагов вероятно у каждого сайта,
  на миде, на подходах — с честным «сколько знаем точно / сколько предполагаем».
- **Углы:** какие входы и углы кто из своих держит сейчас, какие пустые.
- **Свои:** кто где, сколько HP, гранаты, кто перезаряжается.
- **Вход в картину — только общий канал связи:** «вижу» (сразу, как радар),
  «слышу» и слова тиммейта (с задержкой голоса). Никаких записей «прямо в уши».
- **Память о сопернике между раундами** — одна, отдельно от картины раунда.

## 2. Цели (каждая даёт оценку для позиции, взгляда, гранаты)
Держать свой угол / вход · Не умереть зря (укрытие, не один против многих) ·
Быть рядом для размена · Играть на бомбу (плант, дефуз, ретейк, пост-плант) ·
Добыть инфу · План команды на раунд (тактика T, схема CT) — как рамка.
Бот считает «что лучше всего для этих целей сейчас» и делает это. Один
приоритет вместо 9 замков, кто кого перебивает.

## 3. Что удаляем (по шагам, не сразу)
- Лишние хранилища знания: личное «знаю, где враг», «последняя позиция»
  отдельно от карты, «проверили — пусто» в двух местах, старый подсчёт
  «сколько врагов рядом», шесть разных памятей между раундами → одна.
- Обходные «коллы в уши» (5 мест: смерть тиммейта, ослепление, помочь пику,
  дым рассеялся, добить).
- Потом: три голоса «как у про» во взгляде → один вес; дубли гранат и броски
  мимо общей двери; ~35 мест, ставящих позицию, и 9 замков → выбор из целей.

## 4. Что остаётся как есть
Карта, стены, навмеш и пути, стрельба и дуэли, экономика и закуп, физика
гранат, про-лайнапы и про-точки (как кандидаты), войс-журнал для людей,
делёж углов в команде (станет частью выбора взгляда).

## 5. Порядок замены (каждый шаг — проверка на ваших ситуациях и замер 8 матчей)
1. **Знание о врагах** (этот шаг): одна картина, коллы только через общий
   канал. Первым — **К1**: найти и показать момент «увидели 4 на рампе, команде
   всё равно», понять почему, починить через картину.
2. **Взгляд:** одна цепочка, «как у про» — вес внутри дележа углов (В1, В2, В8, К2).
3. **Гранаты:** одна дверь, дубли убрать (Г1, Г2, Г3).
4. **Позиция:** выбор из целей вместо замков — сначала на одном участке
   (сайт B + рампа), потом остальное (П1–П6, К3–К6).

## Шаг 2 подробнее — «взгляд» (согласован 02.10, сделан в v171 — итог в DECISIONS.md)
**Как сейчас.** Одна цепочка, но внутри четыре голоса спорят:
1. «Как у про» на про-точке стоит **раньше** командного дележа углов: бот на
   про-точке смотрит по-про, даже если команда поручила ему другой вход. Отсюда
   «двое в один угол, третий вход пустой» (В8, К2).
2. «Как у про» — из трёх мест: направления про-точки, сетка взглядов из демок,
   угол из про-списков позиций. Они не согласованы.
3. Угол поста («стой тут, смотри туда») — ещё одна отдельная ступень после
   дележа.
4. «Не смотреть в стену» — две страховки подряд **после** выбора: сначала
   выбирают точку за стеной, потом чинят (В1, В5). «Взгляд украдкой на бегу»
   заново считает кандидатов мимо дележа (В2, В7).

**Как будет.** Видимый враг → задачи, где взгляд задан самой задачей (прикрыть
ослеплённого, спам, бросок гранаты, фейк) → **делёж углов команды** → плавность.
Всё остальное — веса кандидатов внутри дележа:
- «как у про» — один источник: на про-точке её направления, иначе сетка из
  демок; это вес, не приказ — порученный командой угол важнее;
- угол поста — вес кандидата (уже есть), отдельная ступень удаляется;
- кандидаты сразу видимые (точка на краю угла, а не за стеной) — две страховки
  сводятся в одну последнюю проверку;
- взгляд украдкой на бегу берёт кандидатов из того же дележа.

**Удаляем:** ступень «про» и ступень «пост» в цепочке, отдельный расчёт про-
направлений про-точки, одну из двух страховок от стены, повторный расчёт
кандидатов на бегу. **Не трогаем:** плавность (v153/v170), делёж углов, стрельбу,
позиции.

**Проверка.**
- Ваши пункты: В1, В2, В5, В7, В8, К2. Если есть скриншоты с номером матча
  и тиком — пришлите, проверю ровно их до и после.
- Детекторы (у про / было / стало):
  - взгляд в стену ближе 1 м, % времени;
  - на бегу смотрит строго по ходу, %;
  - туда-обратно, раз в минуту.
- Детектор «двое рядом смотрят в одну сторону», % времени — только было /
  стало: в данных про нет одновременных взглядов.
- 16 матчей против v170.

**Здоровье, ожидаемо:**
- мест причины взгляда: 12 → ~9;
- источников «как у про»: 3 → 1;
- страховок от стены: 2 → 1;
- переключателей: не больше 139 (уйдут `proSpots`-взгляд, `noWallStare` или `noWallLook`).

**Риск.** «Как у про» по цифрам уже близко — может стать хуже. Покажу честно.
