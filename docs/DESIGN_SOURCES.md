# Источники для дизайна страницы

Перед правкой оформления (табло, панели, эффекты, меню) — сверяться с этими источниками.

## Присланы владельцем 26.10 (v430)
- https://github.com/Moddingflow/better-design — порядок работы над видом: токены, проверка по отрисованной странице, движение с запасным
  вариантом «уменьшить движение», без лишнего текста
- https://ui.watermelon.sh/, https://skiper-ui.com/, https://21st.dev/, https://uiverse.io/, https://www.aisdkagents.com/ — каталоги
  компонентов (React / Tailwind). У нас одна страница без библиотек: берём приёмы, пишем на чистом CSS, библиотеки не подключаем
- https://styles.refero.design/ — каталог дизайн-систем; ближе всего к нам тёмные «пультовые» (Raycast, Auros)

## Присланы владельцем 12.10
- https://github.com/leonxlnx/taste-skill — правила «без шаблонности»
- https://github.com/nextlevelbuilder/ui-ux-pro-max-skill — база стилей, шрифтов, палитр
- https://github.com/VoltAgent/awesome-claude-design, https://github.com/rohitg00/awesome-claude-design — каталоги дизайн-систем
- https://github.com/kylezantos/design-motion-principles — движение (Emil Kowalski, Jakub Krehel, Jhey Tompkins)

## Что применяем (с 26.10, владелец снял ограничения 12.10 «без свечений, только острые углы, минимум движения»)
- Одна система переменных в `src/game/002_style.html` (`:root`): цвета, радиусы `--r-*`, тени `--sh-*`, длительности `--d1..3`, кривые.
  Цвета команд — те же, что у кружков игроков на радаре.
- HUD трансляции (табло, панели игроков, карточка игрока) — острые углы; служебные панели и кнопки — скругление `--r-sm` / `--r`.
- Движение — на события игры и действия: урон, смерть, счёт, деньги, плант, конец раунда, открытие меню. Одно место — `635_hud_fx.js`.
  Только `transform` / `opacity`, без `filter` и размытия фона (дорого на слабом ПК); при «уменьшить движение» — без анимаций.
- Свечение — только на редких событиях: бомба (кромка по краю экрана), клатч, крупный баннер.
- Шрифты — внутри страницы (`001_fonts.html`): Golos Text — интерфейс, Roboto Condensed — подписи HUD, IBM Plex Mono — числа.
- Карту на холсте и маркеры игроков не менять (владелец, 26.10).
- Проверка: снимок страницы 1920 / 1600 / 1366 и время кадра до / после в одном браузере.
