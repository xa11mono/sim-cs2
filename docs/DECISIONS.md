## 20.10.2026 — А3–А4: слои карты Mirage из геометрии игры и зоны по подписям владельца (игра не менялась)
- **Формат для игры — `geom3d/map3d.json`** (устройство — ARCHITECTURE, «Карта 3D»): столбики на сетке VIS (клетка 5 ед.) для взгляда /
  пуль и для гранат, небо, этажи (несколько на клетку), точная геометрия. Луч — столбики (быстрый отсев, всегда с запасом) + точная
  проверка треугольников рядом; образец `tools/map3d/map3d.js` даёт ровно А1: закрыто 0,7 % убийств про, ≈ 8 мкс на луч.
  Почему не одни столбики: при клетке 5 ед. ящики и косяки «толще» на клетку — закрыто 6,5 % (2,5 ед. — 2,9 %); точная проверка — 0,7 %.
- **Этажи** — верх геометрии, обращённый вверх, с местом над ним ≥ 54 ед.; настоящие — достижимые от спавнов (шаг ≤ 18, спрыгнуть,
  лестницы из навмеша, прыжок ≤ 57, с приседом ≤ 66, подсадка ≤ 130 — **подсадка — проектное число**; прыжок 57 — из физики CS2
  (импульс 301,99, гравитация 800), а не 64, как `JUMP_UP` в игре). Под навмешем этаж есть в 98,7 % площади.
- **Слои** (стены, укрытия с верхом, окна, проёмы, крыши, подъёмы, прострелы по материалу и толщине) — от каждого этажа; картинки
  `docs/reports/map3d/a3_*.png`. Невидимые стены вокруг ящиков (playerclip) учтены: стена ищется дальше отступа.
- **Зоны (А4)** — `geom3d/zones_owner.json`: 61 прямоугольник владельца (переписаны с картинки, совмещение с радаром по силуэту — 0,93),
