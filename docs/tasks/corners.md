# Задача: бот видит карту углами (В15)

Сейчас позиция и взгляд решаются по зонам (многоугольники Mid, Ramp…) и по
автоматическим точкам. Зона большая: часть видна, часть за стеной — куда
смотреть внутри неё, непонятно. Отсюда взгляд в стену, «не туда», проверка мест,
куда враг ещё не мог дойти, плохие позиции.

Игрок видит углы: край видимой области, где кончается стена и начинается
проход, — оттуда может выйти враг.

## Что сделать (всё считается по стенам и навмешу, без ручной разметки)
1. **Видимая область** с точки бота (до стен, с учётом дыма).
2. **Края («углы»)**: места, где видимую область обрезает угол стены, — за
   ними может стоять враг. Для каждого края: точка на краю, сторона, куда
   уходит проход.
3. **Опасность края**: может ли враг уже быть за ним и как скоро (тайминг по
   путям от врагов/спавна — REACH), что известно (звук, коллы, видели), держит
   ли этот край тиммейт, не за спиной ли своих.
4. **Взгляд** — на самый опасный край, на уровень головы, чуть за кромку
   (широко/узко по форме угла). Края делятся между тиммейтами (кто ближе / у
   кого лучше линия). Без инфы — края, откуда враг может появиться раньше всего.
5. **Позиция** (в существующем одном выборе действия): кандидаты — места, где
   открыто мало краёв (держишь 1–2 угла, от остальных закрыт стеной) и нужный
   край виден; рядом укрытие. Это заменяет автоматические «укрытия/точки
   встречи» — их и редактор точек удалить.
6. **Префайр** (В11) и **уход от флешки** (В12) — на этих же краях.
7. Зоны — только для названий мест и тимспика; решения по зонам удалить.
8. Показ на радаре (галочка «углы»): у выбранного бота — видимая область,
   края, их опасность, какой держит.

## Проверка
Сначала показать на радаре для 3–4 ботов в одном моменте (видимая область,
края, какой держит) — владелец смотрит глазами. Потом подключать к выбору.
