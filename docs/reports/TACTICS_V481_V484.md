## 2. «Сайт пуст» — калибровка (прогон 133, выборки раз в секунду: CT на сайте по факту и давность проверки точек)
| правило | говорит «пусто», CT там были | ловит пустых |
|---|---|---|
| было: любые 2 зоны в 750 за 12 с | Mirage 92–93 %, Ancient 90–91 % | 8–17 % |
| 3 главные точки за 8 / 12 / 20 с | 57–61 % (Mirage v480) | ≤ 1,5 % |
| 4 главные точки | 40–67 % | ≤ 1 % |
| 6 главных точек (v482–v484) | Mirage 0–1 выборок; Ancient 9–25 выборок, из них с CT 28–56 % | ≤ 1 % |
| 9 точек | не срабатывает | 0 |
Вывод: старое правило в 9 из 10 случаев объявляло пустым сайт, где стояли CT. Проверками T редко покрывают главные точки CT
(«проверено пусто» — 0 %, «частично» 5–9 %, «не проверено» 91–95 % выборок), поэтому ни один вариант «по проверкам» не даёт и
малой ошибки, и заметного охвата. Оставлено 6 точек / 12 с (почти не срабатывает — ложных переколов нет); как T на самом деле
узнают «пусто» без проверки всех точек — вопрос владельцу (BACKLOG 4/25). Число 6 — проектное.
