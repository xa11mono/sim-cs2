## 29.10.2026 — Повтор и после мультикилла, по очереди с клатчем (v466; владелец: «на про почти после каждого раунда повтор; мультикиллы с трёх, двойной — редко; если успеваешь — по очереди, что раньше было»)
- Причина, почему не было (по коду): повтор включался только на выигранный клатч 1v2+ (675, rpRoundEnd).
- Сделано: после раунда — список (R.list) по времени: клатч 1v2+ и мультикиллы (3+ фрага; двойной — в 20 % раундов без другого повода,

  расписал). Проверено: Mirage м1 р1 (облако) — «Повтор · 3 килла · m0NESY», три фрага с замедлением.

## 29.10.2026 — Повтор: звук точного оружия, переход наложением, реакции по очереди с голосом (v465; владелец: «звуки оружия не те», «моргание, цокает», «нет озвучки», «фразы уже готовые висят»)
- Причины (по коду): у выстрела в записи был только класс следа (AK → звук M4, Glock → USP, любой SMG → MP9, глушитель терялся); переход
  между кусками — 0,5 с в чёрное и обратно + свист дважды; 10 голосов реакций запускались за 1,5 с и сбрасывали друг друга (showSay
  отменяет очередь); пузыри фраз стояли в разметке сразу.
- Сделано: след выстрела хранит оружие (wk, sil — только показ); переход — наложение последнего кадра прошлого куска на 0,6 с, без свиста;
  реакции по очереди (rpTalkOrder / rpTalkTick): «…» печатает → фраза, звук чата, голос (5 голосов: клатчер, двое своих, двое соперников),
  следующий — когда голос кончился. Числа (0,45 / 1,1 / 3,6 / 0,85 с) — проектные. Проверено на снимке м17 р27 (облако): чёрных кадров нет,
  реплики идут по одной. Голос в облаке не проверить (нет синтеза речи).

## 29.10.2026 — Дефузер ретейка — кто раньше снимет бомбу (v464; владелец: «почему дефузит не ближайший?»)

  перешла к sh1ro, бомбу сняли. Замер v463 / v464 на 8 матчах обеих карт — на ПК.
