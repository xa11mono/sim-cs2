# Журнал решений (новые записи — сверху)

## 10.10.2026 — Замечание владельца: «бегает по позициям, не доходит, стоит спиной к линии» (v238, игра изменилась)

**Что было (внёс v237).** Перенесённый «держать район» пересчитывал место раз в 2 с и на ходу (правило v166 «пока идёт —
не пересчитывать» не перенесено): по пути ближе к боту оказывались другие клетки — 7,9 срыва за раунд у CT, по ~200 px.
Стоя бот смотрел на «главный вход» района, а без инфы входы почти равны — смотрел куда попало, бывало спиной к линии.

**Что сделано.** Место пересматривается только на месте и только по поводу: знание о врагах рядом (видел / слышал /
войс) или смерть своего; новое — только если лучше нынешнего на `HOLD.better` (1,0, проектное число). Взгляд — по линии
позиции (угол точки из демок), с неё — только по угрозе из знания; к месту ближе 200 px — не отводя прицел с линии. Слой
«позиции»: кружок — место, пунктир — линия позиции, сплошная — куда бот смотрит.

**Цифры (1 матч, проверка без прогона 6 матчей — по просьбе владельца).** Пересмотров места у CT 7,9 → 1,5 за раунд (на
команду), медиана сдвига ~215 px; стоя без угрозы смотрит по линии (±29°) 96 % времени.

## 10.10.2026 — Перенос из v166: «держать район», экономика, гранаты в закупе, AWP (v237, игра изменилась)

**Решение владельца.** Сравнили v166 / v176 / v196 / текущую на 6 матчах: v166 лучше почищенных почти везде (гранаты,
закуп CT, фулл против фулла, AWP, темп). Не откатываться, а переносить из v166 целыми частями; прогон — один раз в конце.

**Что перенесено.** 1) Позиция — «держать район» v166 (`holdSpot`): центр — рекомендованная точка / место полосы,
кандидаты — навмеш до 340 px, оценка по знанию (главный вход по гипотезам, лишние входы, засвеченное место, куча /
кроссфайр, где стоят про — `progrid.json`, путь, инерция), пересчёт раз в 2 с; к месту ближе 200 px — с прицелом на вход.
Убраны зона, микросдвиги, ритм взгляда и поправки прицела v228–v236. 2) Тип раунда — правила v166 + оценка денег
соперника. 3) AWP — снайпер сам или дропом. 4) Гранаты себе — набор по роли, до 4 на фулле (вместо заплатки). Числа
v166 — проектные.

**Цифры (6 матчей; про / v166 / v236 / v237).** Закуп CT фулл/форс/эко 68/13/19 · 62/13/26 · 51/23/25 · 60/17/22; фулл

## 10.10.2026 — «Движение и вид как у про»: нож на бегу, CT держат позицию в движении; сравнение с v166 (v236, игра изменилась)

**Что было.** Нож боты не доставали никогда (у про до планта — 50 % снимков на бегу). CT на 10–45-й с стояли 83 % времени
(у про 25–33 %: остальное — шагом/медленно 42–50 %). Новый замер `tools/measure/movement.py` (про / прогоны): стоит /
медленно / шагом / бегом, нож на бегу, у стены, поворот хода. `measure.py --sim=<абсолютный путь>` замеряет старую сборку
— прогнан v166 (`runs/v166_ref`).

**Что сделано.** Нож (как в v166 — `knifeTick`): бежит, до цели дальше, чем успеть достать оружие, и по знанию врага рядом
быть не может — нож (250 ед./с); увидел врага — 0,4 с достаёт оружие. В v166 нож брали только «до цели > 450 px» — 14 %
бега; это условие заменено. CT на позиции: постоял (0,25 / 0,25 / 0,75 / 1,75 с) — прошёл шагом рядом (5,5 / 12 / 27 /
77 px), откуда виден его угол, не дальше 80 px от середины зоны (проектное число) — отрезки из демок про.

**Цифры (6 матчей; про / v166 / было v235 / стало v236).** CT стоят 39 / 20 / 70 / 37 %; нож на бегу 50 / 14 / 0 / 41 %
(в руках всего 18,9 / 4,7 / 0 / 10,5 % времени); CT на 10–45-й с стоят 25–33 / — / 83 / 42–46 %; CT побед 51,5 / 48,7 /
54,9 / 48,6 %; размен 17,4 / 11,6 / 13,1 / 13,8 %. Хуже про: CT «медленно» 36 % (про 11), «шагом» 6 % (23) — двигаются
мельче и медленнее, чем про; стоя поворот прицела 6,0° (3,5). Ход на бегу прямее, чем у про (поворот 3° против 7°) — так
же было в v166. Гранат CT 6,1 (про 9,9, у v166 — 9,5).
