# Журнал решений (новые записи — сверху)

## 11.10.2026 — Перестрелка по данным: пострелял — за укрытие (v250, пик по данным)

**Почему.** Владелец: «сделай» на план — пик по данным из демок вместо стояния на линии до конца дуэли. У про в
перестрелке: на линии, пока стреляет, потом уход с линии (93 % пауз — со сдвигом, медиана 41–47 px), пауза 1,6 с,
снова выглядывают в 25 % случаев (tools/peek_bake.py, 92 демки, ~24 000 перестрелок).

**Что сделано.** `fightCycleTick` (одно место, из движения в `stepTick`): line → off (`fightCover`: ближайшее место
в пределах сдвига про, откуда врага не видно) → пауза → back с долей repeek → line. Все числа — квантили из демок
(`PEEK_PRO`), проектных чисел нет. Убраны `peekType` (широкий/плечо/джиггл), фиксация пика «пока видит врага»,
стрейф `_ds`/`duelStrafeOk`, флаги `smoothPeek`, `duelStrafe`, `midStrafe`; ярлыки `_plannedPeek`.
Детектор `tools/measure/peek.py` (тот же код, выстрелы прорежены как в демках); `tools/measure/duel.py` теперь
тоже прореживает (раньше сравнение «пуль на фраг» было нечестным).

**Цифры.** 12 матчей (про / v249 / v250): победы CT 51,5 / 48,4 / 48,1 %; плант 58 / 72 / 72 %; первый фраг за T
43,7 / 48,1 / 49,6 %; размен 17,4 / 11,6 / 11,5 %; 3+ фрага у одного 32,5 / 42,5 / 45,3 % — всё в пределах разброса.
Перестрелок без фрага и смерти 56 / 15 / 12 % — не сдвинулось: перестрелка ботов решается за 0,1 с (у про 0,4–0,55 с),
до ухода с линии не доходит. Ожидали: смертельность контакта → 26 %; получили: 40 → 40 %.

## 11.10.2026 — Позиции парами: с кем стоят про (v249, пункт 1, вторая часть)

**Данные.** `tools/player_positions_bake.py` теперь считает и «вместе»: в скольких раундах на двух позициях одной
стороны одновременно стояли двое из одной команды (92 демки; поле `w` в KNOW_POSITIONS).

**Что сделано.** `posPairLift`: насколько чаще про встают на позицию, когда тиммейт стоит на другой, чем случайно
(lift = раундов вместе × всего раундов / (раундов на одной × на другой)), лучший из тиммейтов; умножает `posPref`
до планта (выбор позиции CT по названию, «держать район»). Нет тиммейтов на позициях демок — ×1.

**Цифры (12 матчей; про / v248 / v249).** Цель не сдвинулась: свой рядом при смерти CT 61 / 45 / 42 %, T 71 / 51 / 51 %;
CT до ближайшего тиммейта на 30-й с 237 / 252 / 251 px. Сдвинулось к про (может быть и разброс): победы CT 51,5 /
40,5 / 48,4 %; первый фраг за T 43,7 / 55,2 / 48,1 %; плант 58 / 79 / 72 %; ранние смерти CT 1,29 / 1,77 / 1,63. Хуже:
3+ фрага у одного 32,5 / 37,8 / 42,5 %; ранние смерти T 1,49 / 1,64 / 1,79.

## 10.10.2026 — Размен — тот, кто рядом; по одному в тот же угол не идут (v248, разбор «как про», пункт 1)

**Данные (92 демки, новые скрипты).** `tools/trade_bake.py`: разменявший был не дальше 272 ед. карты от места смерти
своего в 80 % разменов (медиана 121); «второй погиб от того же убийцы за 5 с рядом» — 11,8 % смертей; размен за 3 с —
9,4 % (у 12-матчевого набора pro.json — 17,4 %: наборы про расходятся). `tools/alone_bake.py`: свой ближе 350 в момент
смерти до планта — T 71 %, CT 61 % (в pro.json — 75,5 % на всех).

**Что сделано.** Одно число размена `TRADE_R = 272` (из демок) вместо 300/320/350/450/700 в «есть ли кому разменять».
Разменивает только тот, кто в TRADE_R от места смерти. Убийца уже убил нашего рядом за 5 с — менять только вдвоём.
Ранний пик CT «за инфой» и агрессивный добор после фрага — только с тиммейтом в TRADE_R. После фрага решение по
известным врагам (ЛИП ≤ 5 с), а не по настоящим позициям (было подглядывание). Детекторы: `tools/measure/alone.py`,
`trade_chain.py`.

**Цифры (12 матчей; про / v247 / v248).** «По одному в тот же угол» 11,8 / 13,3 / 11,1 %; свой рядом при смерти T 71 /
49 / 51 %, CT 61 / 42 / 45 % (почти не сдвинулось); ранние смерти CT 1,29 / 1,93 / 1,77, T 1,49 / 1,76 / 1,64; 3+ фрага у
одного 32,5 / 42,1 / 37,8 %. Хуже: плант 58 / 75 / 79 %, последний против 2+ 10,2 / 18,5 / 21,4 с; победы CT 44 → 40 %
(в пределах разброса 12 матчей).
