## 10.10.2026 — Замечание владельца: «бегает по позициям, не доходит, стоит спиной к линии» (v238, игра изменилась)

**Что было (внёс v237).** Перенесённый «держать район» пересчитывал место раз в 2 с и на ходу (правило v166 «пока идёт —
не пересчитывать» не перенесено): по пути ближе к боту оказывались другие клетки — 7,9 срыва за раунд у CT, по ~200 px.
Стоя бот смотрел на «главный вход» района, а без инфы входы почти равны — смотрел куда попало, бывало спиной к линии.

**Что сделано.** Место пересматривается только на месте и только по поводу: знание о врагах рядом (видел / слышал /
войс) или смерть своего; новое — только если лучше нынешнего на `HOLD.better` (1,0, проектное число). Взгляд — по линии
позиции (угол точки из демок), с неё — только по угрозе из знания; к месту ближе 200 px — не отводя прицел с линии. Слой
«позиции»: кружок — место, пунктир — линия позиции, сплошная — куда бот смотрит.

**Цифры (1 матч, проверка без прогона 6 матчей — по просьбе владельца).** Пересмотров места у CT 7,9 → 1,5 за раунд (на
команду), медиана сдвига ~215 px; стоя без угрозы смотрит по линии (±29°) 96 % времени.
