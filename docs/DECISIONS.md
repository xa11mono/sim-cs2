# Журнал решений (новые записи — сверху)

## 10.10.2026 — Знание о врагах из переделки вместо растекания весов v166 (v240, просьба владельца)

**Почему.** Владелец: «сохрани систему весов и поменяй её на восприятие и гипотезы; добавь позиции из демок». В v166 карта
«где может быть враг» растекалась по зонам сама (`beliefTick`, `m=0.12` к сайтам) — отсюда «вес соседней зоны растёт,
бот отворачивается».

**Что сделано.** Веса v166 — в ветке `v166-weights`. В `game.html` — знание из `rebuild-v238/09_knowledge.js` (гипотезы
held / moved / moved_unknown, числа `KNOW` — проектные числа переделки): глаза + радар (кого видит любой живой свой),
уши `hearReal` (все настоящие звуки v166), войс v166 (`intelPush` → `knowVoice`, только зона), киллфид (`knowKill`),
«проверил — пусто» (`knowClearZone`, свой взгляд — `knowLook`, теперь и для веток «ушёл туда»). `beliefTick` больше не
растекает: карта команды = среднее гипотез живых тиммейтов (moved — где бегущий был бы сейчас по таймингу маршрута;
moved_unknown — по типичным местам врага, проверенные — ноль; убийца, которого не видели, — по зонам, откуда простреливается
место смерти). Убраны: растекание, `beliefSet`, `beliefClearAt`, потенциалы `potT/potCT`. Тайминги `reach*` — как в v166.
Места про из 88 демок (`KNOW_POSITIONS`) — варианты в `holdCands`, выбирает та же оценка v166.

**Цифры (6 матчей, до двух последних правок).** Отворот стоя без инфы (матчи 3, 7): 1,44 → 1,10 в минуту. Взгляд
туда-обратно 1,14 → 0,99 (про 0,8). **Хуже: CT выиграли 48,7 → 30,4 % (про 51,5)**, смертей CT до 45 с 1,87 → 2,16,
гранат CT 9,5 → 7,5. Найдено две причины и исправлено (без нового прогона): убийцу «ставили» на место смерти своего, а не
туда, откуда простреливается; ветка «ушёл туда» не гасла, когда CT смотрел на её зону и там пусто.

## 10.10.2026 — Возврат на v166 (v239, решение владельца)

**Почему.** На шести матчах v166 ближе к про, чем переделка v197–v238 и почищенные v176 / v196: гранаты, закуп CT,
фулл против фулла, темп, AWP; на глаз движение живое. В v166 владелец правил по сути одно (вес соседней зоны растёт сам —
бот отворачивается), в переделке — почти всё, и правки (с моими придуманными числами и правилами) не давали результата.

**Что сделано.** Игра — снова v166: `src/game.html` = `sim_built_v166.html` (проверено: матч бит в бит), подпись версии
«239 (= v166)». Модульная переделка (`src/js`, `src/page.html`, `src/data`) удалена из main, целиком — в ветке
`rebuild-v238`. `build.py` / `mkpub.py` — под один файл. Что менять дальше — `docs/V166_CHANGES.md` (список владельца:
восприятие и гипотезы из переделки, недочёт с весом соседней зоны, гранаты — часто и по делу, позиции из демок —
рекомендованные, по инфе, прошлым раундам, оружию и навыку).

## 10.10.2026 — Замечание владельца: «бегает по позициям, не доходит, стоит спиной к линии» (v238, игра изменилась)

**Что было (внёс v237).** Перенесённый «держать район» пересчитывал место раз в 2 с и на ходу (правило v166 «пока идёт —
не пересчитывать» не перенесено): по пути ближе к боту оказывались другие клетки — 7,9 срыва за раунд у CT, по ~200 px.
Стоя бот смотрел на «главный вход» района, а без инфы входы почти равны — смотрел куда попало, бывало спиной к линии.

**Что сделано.** Место пересматривается только на месте и только по поводу: знание о врагах рядом (видел / слышал /
войс) или смерть своего; новое — только если лучше нынешнего на `HOLD.better` (1,0, проектное число). Взгляд — по линии
позиции (угол точки из демок), с неё — только по угрозе из знания; к месту ближе 200 px — не отводя прицел с линии. Слой
«позиции»: кружок — место, пунктир — линия позиции, сплошная — куда бот смотрит.

**Цифры (1 матч, проверка без прогона 6 матчей — по просьбе владельца).** Пересмотров места у CT 7,9 → 1,5 за раунд (на
команду), медиана сдвига ~215 px; стоя без угрозы смотрит по линии (±29°) 96 % времени.
