# Ручная кросс-браузерная приёмка (критерий Р8 № 24) — чек-лист владельца

Сборки: `mirage-radar.html`, `ancient-radar.html` — страницы для игроков ветки `v642a` (игра — принятая архитектура `457df246`; симуляция по
умолчанию в Worker). Открывать двойным щелчком (file://), без сервера. Браузеры: **Chrome, Brave, Opera GX, Edge, Firefox, Safari**.
В каждом браузере — обе страницы. Отметка: ✓ работает · ✗ не работает (что видно; снимок экрана) · — не проверялось.
Консоль ошибок — F12 → «Консоль» (Safari: «Разработка» → «Показать веб-инспектор»; меню «Разработка» включается в настройках «Дополнения»).

| # | что сделать | что должно быть |
|---|---|---|
| 1 | Открыть страницу, подождать 5 с | радар карты, табло, игроки; разминка идёт (боты двигаются); в консоли нет красных ошибок |
| 2 | «Сыграть» | начинается матч 1, таймер раунда идёт, тики в заголовке растут («матч 1 · тик …») |
| 3 | «Пауза», затем снова | на паузе всё стоит (тик не растёт), после — идёт дальше |
| 4 | Скорость (если есть ×2 / ×4) и «10 с» назад | ускоряется; перемотка возвращает на 10 с, игра продолжается |
| 5 | Табло и карточки игроков: щелчок по игроку | выделяется, камера / карточка следует за ним |
| 6 | «Слои»: включить все по очереди | рисуются, страница не замирает |
| 7 | «3D», затем вид от первого лица (если доступен), затем обратно | 3D-вид рисуется и вращается; возврат в 2D без ошибок |
| 8 | Звук (кнопка динамика) | слышны выстрелы / шаги / гранаты; выключение — тишина |
| 9 | «Отметить» (или клавиша M): написать текст, сохранить; «Отметки» — открыть список; «В файл» | отметка в списке; файл скачивается; открытие отметки из списка показывает тот момент |
| 10 | «Обсервер» (O) | автокамера переключается на бои |
| 11 | «Песочница»: поставить бота, отдать приказ, выключить | бот появляется и идёт; после выключения игра продолжается |
| 12 | «Демка»: открыть раунд из демки | раунд проигрывается |
| 13 | Повтор клатча (если в раунде был клатч) | повтор открывается и проигрывается |
| 14 | «Инструменты» → редактор карты / зон: открыть, закрыть без сохранения | редактор открывается, рисует, закрывается |
| 15 | Новый матч: номер 3 → «Сыграть» | начинается матч 3 |
| 16 | Оставить матч на 5 минут, во время игры прокручивать / нажимать кнопки | интерфейс отзывчивый, не замирает (симуляция в Worker) |
| 17 | Та же страница с `?worker=0` в конце адреса (главный поток — резерв) | всё как выше; на первом тике раунда и при броске гранаты допустима короткая заминка (известный недостаток: медленные тики не устранены) |
| 18 | Свернуть вкладку на 1 минуту, вернуться | игра продолжается без ошибок |

Результат — таблица «браузер × пункт» (можно фото / снимки экрана). Найденное — в `00_PLAN.md` по правилам `AGENTS.md`.
