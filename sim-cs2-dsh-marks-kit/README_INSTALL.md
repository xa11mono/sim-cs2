# Установка инструкций отметок для DeepSeek Harness

1. Распакуй ZIP **в корень локального репозитория sim-cs2**. Внутри есть путь `.agents/skills/sim-cs2-marks/SKILL.md`.
2. Убедись, что активный DSH-профиль обнаруживает проектные skills. Для стандартного локального провайдера DSH нужны `@deepseek-ai/dsh-skill`, `@deepseek-ai/dsh-skill-filesystem` и `@deepseek-ai/dsh-tool-skill`.
3. Открой DSH-сессию с рабочей папкой этого репозитория. Проверь каталог skills и вызови `/sim-cs2-marks`.
4. Скопируй `PROMPT_FIRST_RUN.md` в DSH как первое задание. Оно специально просит сначала провести read-only диагностику и не менять код до отчёта и согласования.

Важно: сам skill обучает DSH рабочему процессу, но не создаёт доступ к закрытой Claude Artifact DB и Assets. Это отдельная техническая часть первой задачи.
