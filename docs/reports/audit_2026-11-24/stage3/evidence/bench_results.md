## Как повторить

Из папки `stage3/bench` (Node 18+, Rust stable с целью `wasm32-unknown-unknown`; `rdj/target/` в репозиторий не кладётся):

1. `cargo build --release --manifest-path rdj/Cargo.toml --target wasm32-unknown-unknown --lib` — ядро WASM; `cargo build --release --manifest-path rdj/Cargo.toml` — нативные `bench`, `tri`.
2. `node bench.js` — JS A (объекты) и B (массивы); `node bench.js wasm` — плюс Rust → WASM; `rdj/target/release/bench` — Rust нативно.
3. `node tri.js`, `node tri_wasm.js`, `rdj/target/release/tri` — геометрия «отрезок × треугольник».
4. `node exact2.js` — совпадение JS ↔ Rust при `sqrt` в обоих (ожидается 0 / 3000). `exact.js` сравнивает JS с `Math.hypot` против
   текущего Rust (`sqrt`) — расхождение есть; цифра 384 / 3000 получена, когда Rust тоже считал `f64::hypot`.
5. `graph.json` выгружен из страницы скриптом `export.js` (Mirage); `cnt.js` (счётчики вызовов) и `mem.js` (память) работают с копией сборки `sim.html`.

Замеры сделаны в облачном контейнере; на ПК владельца числа будут другими (этап R0).
