# Журнал решений (новые записи — сверху)

## 11.11.2026 — (v551) подъём по пути; прыжок с инерцией
- Прыжок подъёма — по связи графа, по которой построен путь (самый частый в демках на связь), из самой точки отталкивания (≤ 8 px, ждёт ≤ 0,25 с).
- Подъём ≥ `CLIMB_TRUST_N` 100 раз в демках не отбрасывается 3D-шагом (проектное); участок низа — под точкой отталкивания из демок.
- Полёт — постоянная скорость, без остановки на ящике; разворот на месте — только если смотрит назад (> 90°, проектное); кружок +12 %.

## 11.11.2026 — (v550) прыжки плавно; радар Mirage 2048
- Подъём через ящик: прыжок → остановка `CLIMB_DWELL` 8 тиков (порог стоянки сборщика из демок) → прыжок (`climbPhase`); в прыжке — smoothstep;
  тень и ободок — по высоте прыжка. Разгон перед ящиком не делаем: у про его нет (93 ед./с перед прыжком, 103 запрыга).
- Радар Mirage: пробовали картинку владельца 2048 px — владелец попросил вернуть прежнюю, `radar.png` прежний.

## 11.11.2026 — (v549) прыжок лицом к прыжку; окно; шифт
- Углы взгляда в прыжке — на карте (yaw0 / yawM / yaw1 из демок), не к направлению «низ → верх». Прыжок — только лицом (≤ `JUMP_FACE` 45° к
  направлению прыжка бота), иначе разворот на месте ≤ `JUMP_FACE_WAIT` 0,5 с — проектные числа.
- `CLIMB_MAX_STEP` 68 → 76 — по демкам (72 ед. берут без буста). Участок — конец подъёма / прыжка из демок — не выкидывается из графа без пола в 3D.
- Прыжок через щель на шифте тихий, если в демках так прыгали ≥ `GAP_WALK_N` 3 раз (скорость перед отталкиванием ≤ 150 ед./с) — проектные.
