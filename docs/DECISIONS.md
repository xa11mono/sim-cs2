## 09.10.2026 — Этап 2, шаг 10б: знание карты — типичные места врага (v211, игра изменилась)
- **Почему:** после шагов 9–10 префайр и гранаты «себе» почти не включались — повод был только «весомая
  гипотеза» (≈1 % времени), а про проверяют углы и флешат выход по знанию карты, не только по свежей инфе.
- **Новое в `09_knowledge.js`:** `K.spots` — стандартные точки врага из `positions.json` (без подпушей), без
  «кто» и весов. Место открыто, пока бот сам не увидел его пустым (`knowLook`) и если враг успел бы до него
  добежать со спавна (`knowSpotReach`); снова открывается по звуку/войсу в той зоне (`knowApply`).
- **Читают:** взгляд `posAhead` (11_position.js; заменил `posPrefire`) — гипотеза ≥ 0,5 → префайр, иначе
  проверка ближайшего открытого места впереди (`check`, готовность `setup_default`); `selfExit` (13_nades.js) —
  флешка под выход и по типичному месту, но только под близкий выход (≤ `SELF.spotNear` 350 px). Гранаты
  «себе» берутся только из купленных себе (`b._selfN`), сценарные не трогаются.
- **Итог (6 матчей, v210 → v211, про):** на бегу взгляд по ходу 88,8 → 59,3 % (53,2); решений «себе» 0,09 →
  0,85 на раунд; флешка под выход по определению про T 0,06 → 0,31 (0,69), CT 0,01 → 0,12 (0,57), подтверждено
  делом 42 %; гранат CT 0,02 → 0,23 (9,9), T 4,3 → 4,5 (9,4); стоял против шёл — первым стрелял стоявший
  87,8 → 79,8 % (61,3); размен за 3 с 2,2 → 4,8 % (17,4). CT выиграли 19,6 → 14,3 % — в пределах шума (91 раунд).
