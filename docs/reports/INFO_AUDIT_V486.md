## 2. Найдено
| # | что | тип | статус |
|---|---|---|---|
| И1 | сигнал `kill` команде убийцы нёс **настоящую роль** убитого в этом раунде (`victim.tRole`); T решали по ней «сняли опорника — заходим», «минус на другом сайте — перекол» | скрытая инфа | **исправлено v486**: роль — по памяти команды (`knownRole`: `ctHabit` → район места) |
| И2 | `knowSetupRead` (расстановка CT) считает только **увиденных** CT; убийца, которого жертва не видела, даёт только «звук» (место выстрела) — в чтение расстановки не входит | потеря инфы (частично) | не правилось: место по выстрелу ±90 px — вывод, не наблюдение; решение владельца |
| И3 | гипотезы врагов от звука привязываются к конкретному игроку (`beliefLast` по id из гипотезы, 240) | вывод, не наблюдение | так задумано (знание держит гипотезы по каждому врагу); имя по шагам игроки не узнают — проверить, не попадает ли имя в коллы |
| И4 | CT «сайт пустой» (`undefended`) входил в счёт T | смешение «нет защитников» и «нет T» | исправлено v483 |
| И5 | гранаты без контакта давали колл «выход ~3» | вывод сильнее наблюдения | исправлено v482 (прогон 133: слепые ротации 0,33–0,45 → 0,03–0,06 на раунд) |
| И6 | T «сайт пуст» по 2 зонам — ложно в 90–93 % | неверный вывод | v482 — 6 точек (почти не срабатывает); переработка — этап «оценка сайта» (`docs/reports/TACTICS_V481_V484.md`) |

## 3. Что не проверено
- Сквозные сценарии из задания (второй опорник B убил на A и т. п.) — сторож прогона 137 пишет оценку знания T по сайтам; разбор после
  прогона. Отдельные воспроизводимые сцены (снимок раунда) не делались.
- Устаревание: у каждого типа своё (гипотезы по путям и времени, `KNOW.memSec`, свежесть `beliefSeen` 10 с в `beliefCount`), но
  калибровку возраста информации против факта не мерили.
