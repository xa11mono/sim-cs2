# Среда проверок (выбрана 24.11.2026; закрепление — шаг Р0.1)

Почему важно: реализация `Math` различается между версиями движка JS; при разнице в 1 ulp тот же матч расходится с первых тиков
(`docs/reports/audit_2026-11-24/stage4/evidence/game_math_sensitivity.json`). Отпечатки «бит в бит» сравнимы только в одной среде, пока
не принят этап Р2 (`dmath`). Каждый отпечаток, запись матча и отметка записывают среду.

**Уточнение 25.11 (прогон 314):** одна версия Playwright не означает один браузер. На ПК Playwright 1.63.0 ставит свой Chromium
**153.0.8010.12** (Windows 10, Node 24.21.0, V8 13.6); в облаке при той же 1.63.0 — предустановленный Chromium **158.0.8127.36** (Linux,
Node 22.23.5). Отпечатки облака и ПК тем не менее совпали на всех досчитанных матчах (7 из 7 Ancient; Mirage — досчёт). Совпадение двух
сборок движка — факт этих матчей, а не гарантия: гарантию даёт только `dmath` (Р2). Каждый результат хранит `env.json`.

## 4. Известная совместимость и ограничения (Р0.2, Р0.14)

Стенд https://claude.ai/artifact/6cjBWQnz7BcZXqahNv2zGu (исходник — `docs/reports/audit_2026-11-24/stage4/bench/make_probe.js`).

| возможность | страница-артефакт, Brave 158 / Windows (владелец) | файл `file://`, Chromium 158 / Linux (облако) |
|---|---|---|
| WASM внутри HTML — синхронно и асинхронно | работает | работает |
| Rust `libm` в WASM = нативный Rust (бит в бит) | да | да |
| Worker из Blob-URL (обычный) с WASM | работает | работает |
| Worker из Blob-URL (модуль) с WASM | работает | **не работает** |
| Worker из `data:` | **не работает** | работает |
| `SharedArrayBuffer`, изоляция страницы | **нет** | нет |
| вызов WASM / JS, нс | 2,51 / 0,32 | 2,63 / 0,45 |

**`Math` браузера** (хэши 20 000 входов, `stage4/evidence/artifact_probe_refs.json`): Brave 158 / Windows совпадает с Chromium 158 / Linux
в sin, cos, tan, atan2, exp, log, hypot, sqrt и **различается в `pow`**. В коде расчёта `Math.pow` — 8 мест, в том числе падение урона
с расстоянием (450:51, 470:186, 490:295). Значит, одна версия Chromium на Windows и Linux может дать разные матчи; проверка — Р0.1
(отпечаток ПК против облака). Устраняется только `dmath` (Р2).

**Следствия для устройства** (`docs/architecture/DECISIONS.md` АР-24…АР-26): кадры из Worker — через `postMessage`, общая память — только
необязательное ускорение; Worker — из Blob-URL, не из `data:`; запасной режим — главный поток.

Firefox, WebKit, Opera GX, Edge, Safari — не проверены (шаг Р0.14).
