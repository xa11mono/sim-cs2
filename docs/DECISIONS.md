## 12.10.2026 — Этап 4 аудита: молотов в реальной точке вспышки, угол «под ногами», данные для перестрелок (v268)

**Что.** По ТЗ владельца «Этап 4» (отчёт `docs/reports/BOT_BEHAVIOR_AUDIT_PHASE4.md`). Молотов: прямой бросок вспыхивает на
~27 px ближе цели (загорается при скорости < 70), а проверка «свой в радиусе» смотрела только точку цели и без самого
бросающего — опорник CT горел в своём «задержать выход». Теперь проверяется реальная точка вспышки и бросающий: бросивший
в огне 10 → 3, урон себе от гранат 252 → 118 HP на 100 раундов. Взгляд: запомненный угол `cornerLook` берётся, только если
он дальше 30 px (как и новый): «угол под ногами» 18/26 → 1/26 держащих; глобальные метрики взгляда не сдвинулись. Смена
сайта: B→A и «бомба у старого сайта» — 0 необъяснённых. Перестрелки и флешки — **данных недостаточно**: `parse_demos.py
--events` (все выстрелы, урон, ослепления, снимки боя 32 Гц) ждёт запуска у владельца; грубо (16 тиков) — после попадания
боты реагируют как про, но попадание застаёт их стоящими в 61–63 % против 26 %. held не трогали (решение владельца).
**Цифры (про / v267 / v268, наборы A+B+C, 36 матчей).** CT выиграли 51,5 / 52,4 / 50,1 % (интервал −6,5…+1,9 — шум).

## 12.10.2026 — Этап 3 аудита: огонь своего молотова, колл «флешу», угол при переминании; изоляция belief (v267)

**Что.** По ТЗ владельца «Этап 3» (отчёт `docs/reports/BOT_BEHAVIOR_AUDIT_PHASE3.md`). P1-4: «рывок от застревания» и выход
из стены больше не переносят бота в огонь (путь сквозь свой молотов: 14 → 0 заходов на 12 матчей). P2-2: колл «флешу!» в
войсе; ×0,18 «свой отворачивается» — только дослушавшим колл до хлопка (своих ослеплено 0 → 23 на 100 раундов; с про не
сверено — нет `player_blind`). P2-1: `cornerLook` у держащего пост — от точки, где встал (`_hold`): поворотов ≥20° при
±24 px 13 → 4; побочно врагов ослепляется +21 % на раунд. P0-1: правка «время на виду как у про» откатана (смертность
встреч 86 → 87 %); подтверждено — стоят на виду под огнём 52 % времени против 28 % у про, урон в первом окне выше на 18 %.
**Решение по belief (этап 2, P1-2).** 519ebea → c6ab919 на 2 × 12 матчей: ни одна метрика исхода не вышла за 90 % интервал;
у CT масса сайта в `belief` −35 % (ушёл несказанный слух), решения T почти не изменились. Утечку не возвращаем.
P1-3: held «стоял/бежал» 0,50/0,20 против данных про 0,69/0,60 через 5 с — но вес в модели не зависит от времени, а данные
зависят в первую очередь от него; код не менялся, вопрос времени в held — решение владельца.
**Цифры (12 матчей; про / v266 / v267).** Победы CT 51,5 / 54,4 / 53,2 %; раунд 82,6 / 74,7 / 79,7 с; встреча со стрельбой
кончилась смертью 70 / 86,3 / 87,0 %; урон своим от молотова 250 → 206 HP.

## 12.10.2026 — Этап 2 аудита: реакция по цели, карта команды из общего знания, подготовка нового сайта (v266)

**Что.** По ТЗ владельца «Этап 2» (отчёт `docs/reports/BOT_BEHAVIOR_AUDIT_PHASE2.md`). P0-2: реакция и доводка прицела —
по каждой цели (`_ts[id]`), а не по контакту бота с кем угодно: выстрел по второму врагу раньше 150 мс 34 → 15 %.
P1-2 (**решение по принципу**): «общая картина команды» = то, что команда знает вся — радар, войс, киллфид, HUD. Карта
`belief` (её читают взгляд, позиция, коллы CT, IGL T) строится из «слушателя команды» `teamAgent`, а не из среднего
личных гипотез тиммейтов (с v240 туда попадал несказанный слух). P1-1: после смены сайта группы тактики встают на
подготовку нового сайта (раньше — `stageB:Donut` у A). Не исправлено, разложено: движение в перестрелке (P0-1),
огонь своего молотова (P1-4), повороты взгляда (P2-1, попытка откачена), флешки своих (P2-2, данных нет). P1-3: по
88 демкам «забывает слишком медленно» не подтвердилось — в первые 5–10 с модель, наоборот, занижает «остался».
**Цифры (12 матчей; про / v265 / v266).** Победы CT 51,5 / 49,4 / 54,4 % (на грани шума, связь с P1-2 не доказана);
раунд 82,6 / 81,2 / 74,7 с; встреча со стрельбой кончилась смертью 70 / 87,5 / 86,3 %.
