# dmath — прототип общей математики (Р0.12, 24.11) — ВНЕ ИГРЫ

Перенос Rust `libm` 0.2.16 на JavaScript (`dmath.js`, таблицы — `tables.js`, извлечены скриптом из исходника libm): sin, cos, atan, atan2,
acos, exp, log, pow, hypot (+ sqrt — `Math.sqrt`, правильно округлён везде). Только `+ − × ÷ √` и операции с битами, без FMA. Игра его не
использует до этапа Р2 (`rebuild/MASTER_PLAN.md`).

| команда | что |
|---|---|
| `cargo build --release --manifest-path tools/dmath/ref/Cargo.toml` | эталон: нативный Rust libm той же версии |
| `node tools/dmath/corpus.js sim.html --out=corpus.json [--match=3] [--ticks=20000]` | корпус реальных аргументов Math из матча (вызовы внутри stepTick) |
| `node tools/dmath/check.js [--corpus=corpus.json] [--out=…]` | бит в бит против эталона: случайные, граничные (и все пары), корпус; где Math движка ≠ libm; скорость в Node |
| `node tools/dmath/speed_page.js corpus.json` | скорость dmath против Math.* в Chromium на корпусе |

## Итог 24.11 (`rebuild/evidence/R0/r0.12_*`)

- **Точность: 0 расхождений с Rust libm** во всех 10 функциях — 200 000 случайных входов на функцию (диапазоны игры + случайные биты
  по всему double, включая большие аргументы sin / cos через rem_pio2_large), 45 граничных значений и все их пары (2025) для atan2 / pow /
  hypot, корпус игры ≈ 927 тыс. уникальных аргументов (Mirage + Ancient, матч 3, 20 000 тиков; JSON теряет -0 и NaN — они в граничных).
- **Нативный libm = libm в WASM** (этап 4, `stage4/evidence/math_node_vs_rust.json`) → TS = Rust нативно = Rust WASM.
- **Контракт.** Отличия JS Math (Node 22) от libm на граничных значениях — в последнем знаке, кроме одного смыслового: `pow(1, NaN)` —
  в JS `NaN`, в libm `1`. Требование к Р2: `dmath` сохраняет поведение JS в особых случаях (и Rust-ядро — тоже), формулы не меняются.
- **Скорость** (нс на вызов; в облаке, при фоновой нагрузке — абсолютные числа приблизительны):

| функция | Node, случайные | Chromium 158, корпус игры |

| sin / cos | 144 / 147 против 50 / 55 | 46 / 30 против 28 / 30 |
| atan / atan2 | 39 / 49 против 28 / 43 | 16 / 41 против 28 / 45 |
| exp / log | 53 / 55 против 23 / 22 | 32 / 54 против 21 / 27 |
| pow | 129 против 72 | 154 против 29 (2083 значения — шумно) |
| hypot | 49 против 35 | 55 против 23 |
