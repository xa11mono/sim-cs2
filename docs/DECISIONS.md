## 11.11.2026 — (v561b) тактики по ответу про и демкам
- Расстановка CT: исходный вес = доля её структуры (A-мид-B к 20 с) у про на этот закуп CT (`MAP.ctshare`, `tools/ct_setup_bake.py`: структура
  наших — какая выходит у ботов в записях прогонов; отсутствующие у нас структуры — ближайшим); сдвиги по знанию — множители (стак ×6 / ×2,
  ретейк ×6 — те же отношения, что были). Минимум 1 % — проектное.

- `EXU` следит за всеми смоками плана (bkey); подмена — линия погибшего с места ≤ 300 px (проектное); успех раунда — 0,25 / 0,1 / 0,6 (проектные).
