## 15.10.2026 — Крыши без дырок, свободный обзор на закупе, анимация покупки, звук прыжков (v322, М14, М27–М29)

**Что.** (1) Крыши Mirage: надписи и значки внутри штриховки — крыша, обрезка по стене радара (было по навмешу — синие
полосы). (2) Закуп: у каждого свой взгляд — держит 0,25–5,75 с, поворачивает на 11–145° (процентили фризтайма из 25 матчей
Mirage), синхронное покачивание удалено. (3) Панели игроков: новая вещь появляется за 220 мс (ease-out, без анимации при
prefers-reduced-motion). (4) Прыжок и приземление — звук (`moveSoundEmit`, одно место для шагов, воды и прыжка), слышно и при
тихом шаге; радиус как у бега — проектное число (csdb.gg: «громко, далеко», без числа).
**Проверка.** 3 раунда на каждой карте без ошибок.

## 15.10.2026 — Группы А–Д: сайты, крыши, прыжки, «низ», гранаты, войс, роли по карте, спавны, обсервер, прострелы Mirage (v321, М2–М7, М10–М15, М18–М26)

**Что.** Карта: границы сайтов — красные квадраты Simple Radar; крыши — из штриховки (потолок видимости); длинные зоны делятся
(«B Stairs → TV»); спавны — случайная точка из мест спавна в демках (обе карты); роли игроков — по демкам каждой карты
(`roles_bake.py`); прострелы Mirage — из демок (14 мест, где убивали сквозь стену; материал — проектное число).
Движение: этаж по высоте (`navAt`), подъём выше 64 ед. — только по навмешу, прыжок и «ниже уровня» видно на радаре.
Гранаты: молотов тушится смоком; флешка — по точкам вокруг взрыва; HE как в CS2 (140 / 98 / броня ×0,575); откуда прилетела
граната — знает команда и говорит в войс; по смокам не стреляют, если за ним некому быть. Решения T: мало CT на сайте —
заходят сразу; переколл, отмена, ротация — в войсе с причиной; «чисто» по пройденным зонам. Обсервер — выход и плант. Закуп —
камера, выброс старого оружия.
**Проверка.** 3 раунда на каждой карте без ошибок; Ancient меняется намеренно (механики). Underpass → Short: в навмеше прохода
нет и в 40 матчах про ни одного перехода — исправлено описание v320 (лестница из .nav связывает Ladder Room с верхним уровнем,
не Underpass). Не сделано: продажа оружия на закупе (М14).
