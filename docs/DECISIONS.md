## 07.10.2026 — v195: места из демок — желательные, не обязательные (П9)
- **Задача владельца:** убрать авто-точки «укрытия по стенам» и редактор точек;
  собрать из демок библиотеку мест, где про держат угол (сторона, район, фаза,
  1–2 направления взгляда), показать на радаре; выбор действия остаётся один;
  взгляд без инфы — как в демках с места, со свежей угрозой — на неё. По просьбе
  «делай всё вместе» шаги шли без паузы на просмотр.
- **Решение владельца (07.10, чат, во время работы): места из демок — желательные,
  а не обязательные.** Бот выбирает место сам по ситуации (что видно, какой вход
  нужен, есть ли укрытие, кто из своих что держит), точка из библиотеки даёт месту
  только небольшой плюс; нет рядом хорошей точки или лучше встать в другом месте —
  встаёт в другом. Первый вариант («только из библиотеки») был уже сделан —
  переделан в этом же чате; начатый на нём прогон остановлен недоигранным и в
  отчёт не идёт. Также: исключение из «демки только для сверки», как лайнапы — из
  демок только где можно стоять и куда смотреть.
- **Библиотека** (`tools/spots_bake.py` → `src/data/spots.json`): «держит угол» —
  стоит 2+ с, не стреляет и не бросает (±2 с), рядом никто не погиб, врагов на
  прямой видимости нет, не ставит и не дефузит. 304 места из 12 демок (3 313
  стояний): CT до планта 134, T до планта 120, T после планта 32, CT ретейк 18; два
  направления — у 60. У CT почти нет мест «вне районов» (4): про туда пикают, а не
  стоят. Страница для глаз — `tools/spots_page.py` (опубликована отдельно).
- **Выбор места (12_team.js, та же сумма целей):** кандидаты — все места карты своей
  стороны (`placesGet`, 01_spots.js: ~400 точек карты на сторону с направлением на
  видимый проход к врагу) + места из демок; место из демок своей фазы +0,3
  (`ACT.W.lib`; свой район 1,6, размен 1,3, угроза входа до 1,0). На радаре —
  галочка «места из демок» (только показ).
- **Взгляд (10_look.js):** на месте из демок своей фазы без инфы — его 1–2
  направления (с двумя — по очереди, доли как в демках); кандидаты-угрозы там —
  только с инфой (враг виден/слышен в зоне ≤8 с или свежая угроза рядом, звук,
  выходы с сайта на сборе ретейка). На других местах — как раньше.
- **Удалено:** 307 авто-точек (`points.json`), редактор точек (`PTED`, панель,
  сохранение в базу страницы, `pointsFromDb`, `pointsApplyPending`), запасной взгляд

  2,7 → 1,3; В8 T 6,3 → 7,1 (ждали ~4); В10 18,7 → 15,4 (21,2). Прочее: раунд 91,0 →
  **85,4** с (82,6); плант 57,9 → 51,6 с (66,3); CT выиграли 45,2 → **41,9%** (51,5);
  смертей до 45 с T 1,29 → 1,83 (1,49), CT 1,10 → 1,63 (1,29) — перелёт; разменяли
