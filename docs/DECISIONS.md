# Журнал решений (новые записи — сверху)

## 09.10.2026 — Аудит, пункт 1: восприятие — звук не теряется, писк бомбы, бомба на земле (v212, игра изменилась)
- **Поломка (docs/AUDIT_v211.md, 1):** `knowHearing` брал только звуки с `s.tick === tick`, а плант, броски
  гранат, начало дефуза делают решения, которые идут в тике ПОСЛЕ `knowTick` — такие звуки в знание не
  попадали никогда. CT не узнали сайт ни в одном из 26 плантов (2 матча), дефузов 0, взрыв в 85 % раундов.
- **Правка (09_knowledge.js, одно место):** каждый звук из `b.ears` обрабатывается один раз (`s.known`),
  когда бы в тике он ни прозвучал (на тик позже — 16 мс). Сравнение по тику удалено.
- **Добавлено, как у игрока:** заложенная бомба пищит (`SOUND.beep`, раз в секунду, 05_bomb.js; радиус —
  как у планта, **проектное число, источника нет — заплатка**); CT видит саму бомбу на земле (в поле зрения,
  не дальше `KNOW.lookRange`); узнавший сайт любым путём говорит «ставят B» в войс (12_team.js). Всё —
  `knowBombSite`. «Бомба видна на радаре CT» — источника не нашёл, не делалось.
- **Итог (6 матчей, v211 → v212, про):** CT выиграли 14,3 → 55,0 % (51,5); раундов 91 → 131; размен за 3 с
  4,8 → 17,6 % (17,4); клатч 50 → 5,6 % (2,1); сейв CT после взрыва 3,97 → 1,31 (2,11); гранат CT 0,23 → 3,28
  (9,9 — ретейк с утилитой заработал). Исходы: взрыв 85 → 39 % (про 17), дефуз 0 → 40 % (14). Сайт на 2 матча:
  CT знают в 29 из 36 плантов (в остальных 7 — сейв, живых 1). Писк и «вижу бомбу» в этих матчах почти не
  понадобились: сайт узнают по звуку планта и войсу ещё до конца планта; они — на случай, когда не слышали.
- **Осталось (аудит 3–11):** T после планта стоят на бомбе (отсюда дефуз 40 % против 14 % у про), CT по ходу
  раунда не двигаются, экономика-заглушка, мало утилиты, первый фраг рано.

## 09.10.2026 — Этап 2, шаг 10б: знание карты — типичные места врага (v211, игра изменилась)
- **Почему:** после шагов 9–10 префайр и гранаты «себе» почти не включались — повод был только «весомая
  гипотеза» (≈1 % времени), а про проверяют углы и флешат выход по знанию карты, не только по свежей инфе.
- **Новое в `09_knowledge.js`:** `K.spots` — стандартные точки врага из `positions.json` (без подпушей), без
  «кто» и весов. Место открыто, пока бот сам не увидел его пустым (`knowLook`) и если враг успел бы до него
  добежать со спавна (`knowSpotReach`); снова открывается по звуку/войсу в той зоне (`knowApply`).
- **Читают:** взгляд `posAhead` (11_position.js; заменил `posPrefire`) — гипотеза ≥ 0,5 → префайр, иначе
  проверка ближайшего открытого места впереди (`check`, готовность `setup_default`); `selfExit` (13_nades.js) —
  флешка под выход и по типичному месту, но только под близкий выход (≤ `SELF.spotNear` 350 px). Гранаты
  «себе» берутся только из купленных себе (`b._selfN`), сценарные не трогаются.
- **Итог (6 матчей, v210 → v211, про):** на бегу взгляд по ходу 88,8 → 59,3 % (53,2); решений «себе» 0,09 →
  0,85 на раунд; флешка под выход по определению про T 0,06 → 0,31 (0,69), CT 0,01 → 0,12 (0,57), подтверждено
  делом 42 %; гранат CT 0,02 → 0,23 (9,9), T 4,3 → 4,5 (9,4); стоял против шёл — первым стрелял стоявший
  87,8 → 79,8 % (61,3); размен за 3 с 2,2 → 4,8 % (17,4). CT выиграли 19,6 → 14,3 % — в пределах шума (91 раунд).
