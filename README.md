# Архив сборок (Р2.1, rebuild/MASTER_PLAN.md)

Сборки, которыми открываются старые отметки. Ключ `index.json` — отпечаток исходника игры (`env.src` отметки, `MK_BUILD` страницы).
Найти и собрать сборку отметки: `python3 tools/marks/mark_build.py --src=<отпечаток> --map=<карта>` (сначала этот архив, потом история git).

- `pre-dmath/` — коммит fbd74738577ebe1f900f3e9f0e9215dd2178caf6 (ветка v599a, метка `pre-dmath` — только в локальном git: прокси среды не пропускает метки на GitHub),
  отпечаток 0d4686fe73618d98: `sim_<карта>.html` (страница замеров с `__ev`), `<карта>-radar.html` (публикуемая страница).
  Математика — Math движка браузера: отметка, записанная в Chromium, повторяется в Chromium той же ОС (rebuild/ENVIRONMENT.md).
