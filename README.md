# sim-cs2 — симулятор раундов CS2 на Ancient

Радар-симуляция 5×5 с ботами, сверка поведения с демками про.

- `ancient-radar.html` — текущая собранная версия (открыть в браузере).
- `src/` — исходник игры: `page.html` + код `js/` + данные `data/` (карта файлов — в начале `docs/ARCHITECTURE.md`); `build.py` собирает `sim.html`, `mkpub.py` — публикуемую версию; `marks.js` — инструмент отметок.
- `tools/measure/` — автозамер 8 матчей и сравнение с про; `results/` — итоги прогонов.
- `tools/` — разбор демок; `tools/diag/` — разовые диагностические скрипты.
- `data/` — выгрузки 10 демок Ancient и обработанные данные про.
- `CLAUDE.md` — правила работы; `docs/ARCHITECTURE.md` — устройство; `docs/DECISIONS.md` — журнал (старое — `docs/archive/`); `docs/PRINCIPLES.md` — список того, как должны играть боты (с отметками «сделано»).
