# Промпты по шагам (каждый шаг — новый чат в проекте)

Порядок — как в docs/DECISIONS.md. Ревизия (docs/AUDIT.md) уже сделана.

## Инструкция проекта (один раз, в настройки проекта)
```
Проект: симулятор CS2 на карте Ancient. Код и документы — в GitHub-репозитории xa11mono/sim-cs2.
В начале каждого чата: подключи репозиторий xa11mono/sim-cs2, прочитай CLAUDE.md, docs/ARCHITECTURE.md и последние записи docs/DECISIONS.md, и следуй правилам из CLAUDE.md.
Я не программист: объясняй простыми словами, без кода в ответах, коротко.
Главное правило: заменять, а не добавлять. Старый код, который делает то же самое, удаляется в той же правке.
В каждом отчёте: что изменилось на моих ситуациях, цифры здоровья кода (было → стало), что не получилось.
Перед крупной работой — план на одну страницу на моё согласование.
В конце задачи: обнови docs/ARCHITECTURE.md и docs/DECISIONS.md, сделай коммит и пуш в main.
```

## Шаг 1 — удалить мёртвое
```
Шаг 1 из docs/DECISIONS.md: удали мёртвый код по списку из docs/AUDIT.md (раздел «Итог» и вердикты «удалить»). Поведение не должно измениться: 8 матчей должны сыграть ровно так же, как до удаления (сравни записи матчей один в один). Покажи цифры здоровья было → стало. Опубликуй симулятор.
```

## Шаг 2 — инструмент «Отметить момент»
```
Шаг 2: инструмент «Отметить момент». Прочитай docs/tasks/02-mark-moment.md и сделай по нему. Мозг ботов не трогай.
Перед кодом — короткий план и макет карточки «Я понял так» с кадром НАСТОЯЩЕГО радара (не схемой), жду моего «да».
В конце: опубликуй симулятор, дай мне отметить 2–3 момента в живом матче и проверь вместе со мной, что всё работает.
```

## Шаг 3 — детекторы
```
Шаг 3: детекторы по пунктам docs/PRINCIPLES.md. Для каждого пункта, который можно измерить, — детектор «сколько раз за матч нарушено», посчитанный у про (демки из data/) и у нас (8 матчей). Разметь в docs/AUDIT.md пункты В3, В4, Э1, Н1 (что в коде им мешает).
Итог — таблица «пункт — у про — у нас», записать в docs/DETECTORS.md. Мозг ботов не меняй.
```

## Шаги 4–7 — новый мозг (по одной части)
Сначала, в начале шага 4, — план всего нового мозга на согласование:
```
Шаг 4. Сначала план нового мозга на одну страницу: одна общая картина команды (что известно о врагах, какие углы кто держит, какие пустые) + несколько целей, из которых бот выбирает позицию, взгляд и гранаты. Что удаляем, что остаётся (карта, навмеш, стрельба, экономика, физика гранат — не трогаем), порядок замены. Запиши в docs/PLAN.md и жди моего «да».
После «да» — делаем часть «знание о врагах»: одна картина, коллы только через общий канал. Первым проверь пункт К1 (колл о 4 врагах на рампе).
```
Шаги 5, 6, 7 — тот же текст, меняется только часть:
```
Шаг <5 / 6 / 7>: делаем часть «<взгляд / гранаты / позиция>» по docs/PLAN.md.
Старые механизмы этой части удали. Покажи: детекторы из docs/DETECTORS.md (у про / было / стало), цифры здоровья кода (было → стало), мои отметки по этой части до/после. Если стало хуже — откати и скажи честно.
```

## Когда видишь плохой момент
С инструментом отметок — просто отметь в симуляторе (M). Без него:
```
Матч <N>, тик <T>, игрок <номер>: <что не так>. Скриншот прикладываю.
Сначала воспроизведи ровно этот момент и подтверди, что видишь то же. Код пока не меняй.
```
