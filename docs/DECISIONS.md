## 09.10.2026 — Аудит, пункт 8: бой — контрстрейф, стоящий больше не выигрывает «бесплатно» (v216, игра изменилась)
- **Поломка (docs/AUDIT_v211.md, 8):** стоял против шёл — выиграл стоявший 66 % (про 50 %). Причина: с
  винтовкой на ходу (> 40 % скорости) стрелять нельзя (`fireReady`), а идущего по пути бота никто не
  останавливал, когда он видел врага: CT на подпуше/ротации, энтри на выходе, ретейкеры, CT, шагающий по
  точке (шаг = 50 % > 40 %), шли дальше и не стреляли.
- **Правка (17_tick.js, движение):** видит врага, в которого будет стрелять, с винтовкой/AWP — гасит скорость
  (контрстрейф) и стреляет; путь не сбрасывается — враг пропал, идёт дальше; это не «застрял». ПП, пистолеты,
  дробовики — на ходу, как раньше. По PRO_PLAY 6а: на ходу пули с разбросом, игроки гасят инерцию и стреляют.
- **Итог (6 матчей, v215 → v216, про):** выиграл стоявший 65,6 → 53,0 % (50,1); первым выстрелил стоявший
  68,3 → 54,9 % (61,3); выиграл выстреливший первым 52,1 → 48,9 % (45,3); **CT выиграли 33,3 → 45,0 % (51,5)**;
  3+ фрага у одного 43,6 → 38,0 % (32,5); после фрага остался 80 → 71 % (56); размен 11,4 → 13,5 % (17,4).
  Первый фраг 12,1 с — всё так же рано (24,7).
