## Как устроен исходник
С v177 игра — маленькие файлы (карта выше). `src/build.py` склеивает их,
вставляет данные из `src/data/` на места меток `@@DATA:…@@` / `@@PNG:…@@` и
генерируемое (список переменных для перемотки, пункты PRINCIPLES, модуль
`src/marks.js`). Склейка дала ту же страницу, что один файл `game.html` (бит
в бит). Инструмент отметок (`src/marks.js`) мозг ботов не трогает; снимок всей
игры — `mkSnapshot`/`mkRestore`, в файл — `mkPack`/`mkUnpack`, открыть
отметку — `mkOpenSnap` (на странице) и `tools/mark_open.js` (без экрана).
История: до v168 — orig.html + 24 патча, v168–v176 — один `src/game.html`.

## Почему так вышло
Каждая жалоба решалась новым правилом на переключателе; старое не удалялось.
Попытка «переделать всё» на ~v145–148 (новый взгляд, оценка угроз, задача
«держать район») тоже добавила новые системы рядом со старыми.

## Из чего состоит (кратко)
- **Карта:** радар Ancient, стены нарисованы вручную (`MANUAL_WALLS`, ~540
  отрезков), навмеш для путей, ~60 именованных зон (`ZONEMAP`, `BZ`).
- **Знание о врагах (с v169 — одна картина на команду):**
  - вход — только общий канал: увидел — сразу (как радар), услышал/сказал —
    когда это договорили в тимспике (`voiceTick` → `intelPush`). Журнал канала
    `teamIntel[team].sig` — лента событий (смерти, фраги, гранаты, звуки);
  - картина — карта вероятностей по зонам `belief` + последнее наблюдение по
    каждому врагу `beliefLast` (с пометкой «проверили — пусто») + `LAST_CLEAR`
    / `REACH`. Читают её через `picKnown` (кому из наблюдений ещё верить),
    `picRecent` (свежие наблюдения), `picNear` / `intelEstimate` (сколько рядом),
    `picOutnumbered` (у точки их на 2+ больше, чем нас);
  - у бота лично — только его органы чувств: что сам видел (`lastIntel`) и
    слышал (`ears`/`heardSound`). Тиммейты туда больше не пишут;
  - колл CT (`ct.call`) — одно место, считает по картине;
  - события (смерти, фраги, звуки по порядку) читаются только через
    `picEvents` — «ленту событий» картины;
  - памяти о сопернике между раундами нет (с v182 удалена вся: `MEMORY`, копия
    между матчами `OPP`, тайм-ауты, выводы перерыва, чтение темпа и стаков,
    привычки CT, где умирали T, куда кидали гранаты). Вернётся позже одним местом
    как часть картины команды. Чтение внутри раунда осталось: закуп врага по
    увиденному оружию (`buyRead`), выход T по гранатам у сайта (`tacRead`),
    ротация CT на слух (`rotRead`) — это восприятие, а не память.
- **Восприятие (с v183, К11) — бот узнаёт о врагах только так, как игрок в CS2:**
  - **уши — одно место `makeSound` (14_movement.js, таблица `SOUND`):** шаги
    бегом (шифт не слышно, вода — слышно), стрельба (глушитель тише), «по мне
    стреляют» (только тому, в кого стреляли), перезарядка (по звуку — каким
    оружием, значит, сколько длится), зум AWP, бросок гранаты, разрыв гранаты
    (слышно или видно), плант, дефуз (начало `defuse`, продолжение `defusing`),
    подбор оружия; `nadefly` — видел полёт гранаты, но не бросавшего → примерно
    откуда кинули. Направление ±6° (через стену ±17°), дистанция ±15% (±30%).
    В услышанном нет ника. У бота — список звуков за 3 с `b.ears`, сколько
    разных источников — `earsSources`; `b.heardSound` — последний. Прыжков в
    игре нет — их звука тоже;
  - **в картину команды** звук идёт через тимспик (`teamInfoTick` → блокнот
    бота → фраза в эфире, см. «Тимспик»); кому из врагов его приписать — `soundWho`: тому, кто по
    картине вероятнее всего там (n источников — n разных врагов). Плант
    («плантят на A») команда узнаёт тоже из колла (`plantHeard`); разрыв гранаты
    врага — `nadeSeen` для чтения выхода;
  - **глаза:** «вижу» — ник и оружие в руках (`buyReadSee` по увиденному);
    бомба у кого / на земле — только если видели; где смок/молотов — видно всем;
  - **киллфид** (`feedKill` → `killfeedRead`): закуп по оружию убийцы; кто с
    AWP. Роль врага по нику — `FOE.roles` (только этот матч): CT — где стоял в
    начале раунда (A/B/мид), T — AWP, первым на сайте (энтри), один вдали от
    своих (люркер); `foeRole` — роль, если видели так 2+ раза. Колл «минус» несёт
    эту догадку, а не настоящую роль;
  - **деньги врага** — подсчёт по открытому (`FOE.money/gun`): $800 в начале
    половины + доход по итогам раунда + фраги из киллфида − что они, скорее
    всего, купили; винтовку сохранил дождавший конца раунда, с которой его
    видели. `enemyEcoGuess` берёт это, а не их деньги;
  - **урон по врагу** — по своему урону (`teamIntel.hurt`), «ослеплён» — если
    флешку на нём хлопнули мы; где убийца, которого не видел, — по направлению
    попаданий; T о дефузе знают, когда услышали начало, кит — догадка по их
    закупу; CT на ретейке берут бомбу там, где её слышно (`ctBombPos`).
- **Тимспик (с v184, К10) — один эфир на команду (конец 09_knowledge.js):**
  - у бота блокнот `_news` (`newsAdd`): что он сам узнал или сделал — увидел,
    услышал (из ушей), умер (говорит «минус» и откуда убили — успевает за 3 с),
    убил, ранил (по своему урону), проверил — пусто, бомба у кого / на земле,
    закуп врага, кидаю гранату, задача сменилась («меняю», «ротируюсь», «сейвлю»…);
  - просьбы — из того, что бот делает, и картины (`talkSelf`): «иду X — нужен
    второй» (иду туда, где враг вероятен, своих рядом нет), «ухожу с X —
    подержите» (держал угол, там никого не остаётся), «стяните одного» (по
    картине их на 2+ больше), «флешку мне на пик» (угол держат, своей флешки
    нет, у соседа есть — `b._peekNeed` из взгляда);
  - план IGL (`talkPlan`): подпись плана команды (T — сайт, фаза, сейв; CT —
    расстановка, колл, сейв, ретейк); сменилась — IGL говорит (на старте —
    закуп и тактика/расстановка, потом «заходим», «перекол», «ротация», «ретейк»);
  - что сказать — `talkTick` раз в 1/8 с: из блокнота — то, чего команда ещё
    не слышала (`teamIntel.said`, 6 с), по важности; одинаковое — одной фразой.
    (с v185) Перед фразой и когда опоздавшая фраза доходит — проверка
    `talkStale`: у записи свой срок (`TALK_TTL`: «вижу» 1 с, шаги 1,5 с, минус и
    бомба 3 с); не говорят, если некому слушать, врагов не осталось, тот враг
    убит, там уже бой (свои видят врага рядом) или команда уже знает новее
    (там видели врага или кто-то погиб после этого). В «минусе» — только кто
    и откуда, без счёта живых.
    Эфир занят двумя+ — только срочное, кто-то говорит — коротко;
  - эфир `VOICE`: фраза 0,5–2 с по числу слов, услышали все в конце
    (`voiceTick` → консоль «[войс CT] ник: …» и сигналы в картину `intelPush`).
    При 3+ голосах сразу несрочное с вероятностью 1/2 пропадает (говорящий
    повторит коротко, если ещё актуально), иначе доходит, когда стихнут
    остальные. Счётчики — `VOICE_STATS`, замер `tools/measure/voice.py`;
  - увиденный враг — сразу на радаре (как в CS2), голосом — «сколько, где, с чем»;
  - реакции на услышанное и ответов «иду / не могу» пока нет (B3). Решения
    команды в консоль — только голосом IGL; прежние строки решений — в отладке.
- **Разметка карты (с v189, rework.md B3 шаг 1; 01_markup.js):** знание карты,
  которое есть у любого игрока, — считается один раз по стенам, навмешу и зонам,

  открыта не больше чем 3 другим направлениям; лучшие — по «вижу проход −
  открыт − другие углы + ближе к стене − далеко от 260 px», не ближе 60 px друг
  к другу. **Точка встречи** укрытия — первая видимая из укрытия точка пути

## Направление (обсуждено 01.10)
Цель — бот «понимает»: одна картина мира (что известно, откуда может выйти
враг) + несколько целей (не умереть зря, держать угол, быть рядом для
размена, играть на бомбу) → действие выбирается из них, а не из сотни
правил «если X — делай Y». Демки — для сверки и для норм, а не для копирования.
Перед этим — ревизия и план на согласование.
