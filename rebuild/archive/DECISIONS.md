# Решения по предложениям других нейросетей (15.11.2026)

Владелец прислал два разбора архитектуры от других нейросетей. Диагноз у них совпадает с нашим; из рецептов взято то, что работает в
этом проекте, остальное отклонено — с причиной.

## Взято
- «Разделение на файлы выдаёт себя за архитектуру» (одна склейка, общее пространство) — главная проблема; фазы 2–3.
- **Три уровня доказательств** (возможная / подтверждённая причина / подтверждённое исправление) — правило `RULES.md` п. 5.
- **Воронка правки** (эпизоды → с причиной → условие сработало → действие выполнено) — правило `RULES.md` п. 6.
- **Ловец писателей полей** — расширить существующий `tools/measure/engine/walk_watch.js`, а не писать заново.
- **Одна цепочка разбора решений** из `LOOKDBG`, журнала решений и сторожей.
- **Симуляция не трогает экран** — 3 файла (см. `FACTS.md`).
- **Схемы данных с проверкой при сборке** (пример — подбор бросков, выкинутый сборкой молча).
- **Собранные страницы — из репозитория** (публикация — инструментом Artifact, не GitHub Actions: собирать при публикации).
- **Стандартные модули `import` / `export` + esbuild** — шаг фазы 2, с отпечатком бит в бит.

## Отклонено
- **Большой аудит-отчёт и 9 документов до начала работ** — недели бумаги, устаревает после первой правки. Карты — генерируются
  скриптом; документ один — «Устройство» (схема + правила).
- **ESLint / dependency-cruiser / Madge / Knip с первого дня** — пока код одна склейка без импортов, они ничего не видят. Полезны после
  перехода на модули; до того — свой ловец писателей и покрытие кода.
- **Дерево на ~60 файлов (`Game.js`, `EventBus.js`, классы)** — шаблон; шина событий в детерминированной симуляции делает порядок
  неявным, а «кто перезаписал решение» — ещё труднее. Структура — от каналов игры: знания, место, взгляд, гранаты, бой, ход,
  исполнители, физика, показ.
- **Юнит-тесты (Vitest) на поведение ботов** — поведение — взаимодействие многих систем, юнит-тест его не ловит. Страховка — отпечаток
  бит в бит, повтор отметок со снимка, набор счётчиков. Юнит-тесты — для геометрии, физики гранат, экономики.
- **«Тысячи раундов за секунды без браузера»** — игра уже идёт без браузера; раунд с навмешем и 3D-видимостью считается десятки
  секунд, скорость упирается в расчёты, а не в отрисовку.
- **«Расхождение двух скриптов сборки»** — проверено: `src/mkpub.py` берёт ту же склейку игры (`gamesrc.game_source`), что `build.py`.
