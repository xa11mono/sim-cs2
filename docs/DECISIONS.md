## 09.10.2026 — Аудит, пункт 8: бой — контрстрейф, стоящий больше не выигрывает «бесплатно» (v216, игра изменилась)
- **Поломка (docs/AUDIT_v211.md, 8):** стоял против шёл — выиграл стоявший 66 % (про 50 %). Причина: с
  винтовкой на ходу (> 40 % скорости) стрелять нельзя (`fireReady`), а идущего по пути бота никто не
  останавливал, когда он видел врага: CT на подпуше/ротации, энтри на выходе, ретейкеры, CT, шагающий по
  точке (шаг = 50 % > 40 %), шли дальше и не стреляли.
- **Правка (17_tick.js, движение):** видит врага, в которого будет стрелять, с винтовкой/AWP — гасит скорость
  (контрстрейф) и стреляет; путь не сбрасывается — враг пропал, идёт дальше; это не «застрял». ПП, пистолеты,
  дробовики — на ходу, как раньше. По PRO_PLAY 6а: на ходу пули с разбросом, игроки гасят инерцию и стреляют.
- **Итог (6 матчей, v215 → v216, про):** выиграл стоявший 65,6 → 53,0 % (50,1); первым выстрелил стоявший
  68,3 → 54,9 % (61,3); выиграл выстреливший первым 52,1 → 48,9 % (45,3); **CT выиграли 33,3 → 45,0 % (51,5)**;
  3+ фрага у одного 43,6 → 38,0 % (32,5); после фрага остался 80 → 71 % (56); размен 11,4 → 13,5 % (17,4).
  Первый фраг 12,1 с — всё так же рано (24,7).

## 09.10.2026 — Аудит, пункт 4 (доделка): подпуш за инфой, смена места после фрага, ротация по войсу (v215, игра изменилась)
- **11_position.js, по PRO_PLAY 3, 5 и демкам:**
  - **подпуш за инфой:** 30 CT-точек `push` из демок (Ruins, Lower Mid, Split, T Lower…) — каждая в раунде с
    вероятностью её доли у про (в сумме ≈ 1 подпуш на раунд), не больше 2; берёт CT со слотом на той же стороне
    (entry → awp → саппорт → якорь последним — **порядок мой, по PRO_PLAY 5: NiKo «инициатор», AWP NAVI начинает
    агрессию**); приходит к типичной секунде точки, стоит её типичное время, потом назад; встретил врага — после
    перестрелки сразу назад;
  - **после своего фрага или пули по нему** (не огня), когда врага не видно 1 с, — на запасную точку или другое
    место точки дальше 40 px, не чаще раза в 5 с;
  - **инфа для ротации** — ещё и доска войса (сказанное команде за 6 с: «несколько B», «шаги Cave»).
- **Итог (6 матчей, v214 → v215, про):** CT гибнут до 45-й с 0,82 → 1,13 (1,29); после фрага отошёл 4,5 → 8,7 %
  (12,6), остался 86 → 80 % (56); CT стоят до планта 96 → 94 % (~40); к сайту выхода 4,8 → 3,8 % (19);
  **CT выиграли 39,2 → 33,3 % (51,5) — хуже:** подпуш стоит CT людей (бой однобокий в пользу стоящего —
  аудит п. 8: выигрывает стоявший 67 % против 50 % у про), а взамен CT ничего не получают (нет AWP, китов,
  утилиты обороны — п. 5–6). Первый фраг 13,7 → 12,7 с (24,7).
- **Чего так и нет:** джиггл (в демках точек `peek` у CT 3 из 86 — опереться не на что); CT стоят 94 % — у про
  движение CT — это ещё и ротации раньше утилиты, и отходы/подходы по звуку, которых у нас мало.

## 09.10.2026 — Аудит, пункт 4: CT по ходу раунда — ротация по инфе, на точке не истуканом (v214, игра изменилась)
- **Поломка (docs/AUDIT_v211.md, 4):** CT с 20-й с до планта стояли 99 % времени (про ~40 %), к сайту выхода
  T с других мест шли в 0 % случаев (про 19 %).
- **11_position.js (одно место на позицию CT), по PRO_PLAY 3:**
  - **ротатор:** раз в 16 тиков CT сверяет «где бьют» по СВОЕМУ знанию — враги, которых он уверенно ставит на
    сторону (`planLocatedList`: видел + войс), и разрывы гранат T у сайта за 3 с (слышал/видел; сколько
    разрывов — столько примерно людей, **допущение**). Сайт X «под выходом» — ≥ 2 (`POS.rotNeed`, «только по
    настоящей инфе»). Идут ближайшие к X не-якоря без врага у себя, пока защитников X меньше
    min(инфа, 3); точка — CT-точка из демок на стороне X (ближайшая, standard лучше). На своей стороне стало
    жарко, а на X нет — назад. Якорь свой сайт не бросает. Только пока план CT — default.
  - **на точке:** раз в 3–8 с (проектное число) — на другое место точки (`spots` из демок) или в пределах её
    `spread`, шагом; пока нет угрозы, врага и контакта 2 с.
- **Итог (6 матчей, v213 → v214, про):** к сайту выхода идут 0 → 4,8 % (19); CT выиграли 36,3 → 39,2 % (51,5);
  взгляд стоя 2,0 → 3,9° (3,5); CT стоят в середине раунда 99 → 96 % (~40) — **почти не сдвинулось**:
  перестановки на точке короткие (десятки px), а ротация включается только по утилите выхода, когда T уже на
  сайте. Клатч 4,2 → 9,1 % (2,1), размен 13,8 → 12,2 % (17,4) — в пределах шума на 130 раундах.
- **Не сделано (дальше по п. 4):** игры за инфой (джиггл/ранний пик/подпуш парой), отход после контакта,
  ротация по ранней инфе (шаги, «несколько B» в войсе до утилиты), фейк — разворот назад.
