# В140: движение ботов против про (облако, короткая проверка)

- Про (12 демок Mirage, `*_motion.csv.gz`): `python3 -I tools/measure/motion/pro_<имя>.py --map mirage` из корня репо —
  `gaps` (нажатия / паузы / та же сторона), `acc` (разгон и торможение), `duck` (присед), `drift` (отход от места стоя), `aimctx` (прицел по ситуациям).
  Общая таблица про — `tools/motion_ctx.py --map mirage`.
- Боты: `bot_motion.js.txt` (выражение для страницы; `__M__` → список матчей, напр. `[3,7]`; 6 раундов на матч), 4 процесса × 2 матча
  (3,7 / 11,13 / 17,19 / 23,29), результаты `bmo_*.json` → `python3 tools/measure/motion/bot_motion_sum.py <папка>`.
  Ситуации — как у про: перестрелка (свой выстрел ±1,5 с), иначе по скорости (< 100 / 100–200 / ≥ 200 ед./с); клавиши бота —
  качание (`_keys`, 540) и стрейф перестрелки (`_fc.sv`, 470).
