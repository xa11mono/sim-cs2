## 09.10.2026 — Аудит, пункт 4: CT по ходу раунда — ротация по инфе, на точке не истуканом (v214, игра изменилась)
- **Поломка (docs/AUDIT_v211.md, 4):** CT с 20-й с до планта стояли 99 % времени (про ~40 %), к сайту выхода
  T с других мест шли в 0 % случаев (про 19 %).
- **11_position.js (одно место на позицию CT), по PRO_PLAY 3:**
  - **ротатор:** раз в 16 тиков CT сверяет «где бьют» по СВОЕМУ знанию — враги, которых он уверенно ставит на
    сторону (`planLocatedList`: видел + войс), и разрывы гранат T у сайта за 3 с (слышал/видел; сколько
    разрывов — столько примерно людей, **допущение**). Сайт X «под выходом» — ≥ 2 (`POS.rotNeed`, «только по
    настоящей инфе»). Идут ближайшие к X не-якоря без врага у себя, пока защитников X меньше
    min(инфа, 3); точка — CT-точка из демок на стороне X (ближайшая, standard лучше). На своей стороне стало
    жарко, а на X нет — назад. Якорь свой сайт не бросает. Только пока план CT — default.
  - **на точке:** раз в 3–8 с (проектное число) — на другое место точки (`spots` из демок) или в пределах её
    `spread`, шагом; пока нет угрозы, врага и контакта 2 с.
- **Итог (6 матчей, v213 → v214, про):** к сайту выхода идут 0 → 4,8 % (19); CT выиграли 36,3 → 39,2 % (51,5);
  взгляд стоя 2,0 → 3,9° (3,5); CT стоят в середине раунда 99 → 96 % (~40) — **почти не сдвинулось**:
  перестановки на точке короткие (десятки px), а ротация включается только по утилите выхода, когда T уже на
  сайте. Клатч 4,2 → 9,1 % (2,1), размен 13,8 → 12,2 % (17,4) — в пределах шума на 130 раундах.
- **Не сделано (дальше по п. 4):** игры за инфой (джиггл/ранний пик/подпуш парой), отход после контакта,
  ротация по ранней инфе (шаги, «несколько B» в войсе до утилиты), фейк — разворот назад.

## 09.10.2026 — Аудит, пункт 3: пост-плант T — места из демок, взгляд, проверка бомбы на дефуз (v213, игра изменилась)
- **Поломка (docs/AUDIT_v211.md, 3):** после планта T стояли на бомбе (73 % времени у бомбы, 98 % стоят; про
  20 % и 40 %) — пост-планта не было, CT дефузили в 40 % раундов (про 14 %).
- **Данные:** `tools/postplant_bake.py` → `src/data/postplant.json` — где T стоят после планта на каждом сайте
  (стоящие снимки `data/pro/pro_samples.csv.gz`, phase post): 12 мест на сайт, доля, средний взгляд, зона.
- **Поведение (12_t_default.js, `tdefPost`):** по PRO_PLAY 6в — разойтись на сильные места с видом на бомбу и
  входы ретейка (кроссфайр), играть на время. Кто куда — лучшая пара «бот — место»: чаще у про и ближе идти
  (`TPOST.walk` 600 px пути ≈ вдвое реже место — проектное число), не ближе 130 px к тиммейту. На месте —
  смотрит, как смотрят про там (`b._ppLook` → `posLook`, 11_position.js). Слышит дефуз (`K.defuseT` — свой
  слух звука дефуза и войс «дефузят!», 09_knowledge.js) — ближайший к бомбе идёт, пока её не увидит.
- **Итог (6 матчей, v212 → v213, про):** у бомбы 73 → 55 % времени (20); дефуз 40 → 23 % раундов (14); взрыв
  39 → 44 % (17); CT выиграли 55,0 → 36,3 % (51,5). **Стало хуже по балансу:** пост-плант держится, а CT почти
  не выигрывают до планта — «все T убиты» 6,5 % раундов против 34 % у про (CT стоят, не играют за инфой, не
  ротируются — аудит, пункт 4). Размен 17,6 → 13,8 % (17,4). У бомбы всё ещё много: ближние места выигрывают
  из-за «ближе идти» и проверяющий идёт к бомбе.
- **Не сделано:** молотов на бомбу под дефуз, фланг ретейка в меньшинстве (Refrag: «меньше — ищи размен»),
  смок на бомбу — утилита пост-планта (аудит, пункт 6).

## 09.10.2026 — Аудит, пункт 1: восприятие — звук не теряется, писк бомбы, бомба на земле (v212, игра изменилась)
- **Поломка (docs/AUDIT_v211.md, 1):** `knowHearing` брал только звуки с `s.tick === tick`, а плант, броски
  гранат, начало дефуза делают решения, которые идут в тике ПОСЛЕ `knowTick` — такие звуки в знание не
  попадали никогда. CT не узнали сайт ни в одном из 26 плантов (2 матча), дефузов 0, взрыв в 85 % раундов.
- **Правка (09_knowledge.js, одно место):** каждый звук из `b.ears` обрабатывается один раз (`s.known`),
  когда бы в тике он ни прозвучал (на тик позже — 16 мс). Сравнение по тику удалено.
- **Добавлено, как у игрока:** заложенная бомба пищит (`SOUND.beep`, раз в секунду, 05_bomb.js; радиус —
  как у планта, **проектное число, источника нет — заплатка**); CT видит саму бомбу на земле (в поле зрения,
  не дальше `KNOW.lookRange`); узнавший сайт любым путём говорит «ставят B» в войс (12_team.js). Всё —
  `knowBombSite`. «Бомба видна на радаре CT» — источника не нашёл, не делалось.
- **Итог (6 матчей, v211 → v212, про):** CT выиграли 14,3 → 55,0 % (51,5); раундов 91 → 131; размен за 3 с
  4,8 → 17,6 % (17,4); клатч 50 → 5,6 % (2,1); сейв CT после взрыва 3,97 → 1,31 (2,11); гранат CT 0,23 → 3,28
  (9,9 — ретейк с утилитой заработал). Исходы: взрыв 85 → 39 % (про 17), дефуз 0 → 40 % (14). Сайт на 2 матча:
  CT знают в 29 из 36 плантов (в остальных 7 — сейв, живых 1). Писк и «вижу бомбу» в этих матчах почти не
  понадобились: сайт узнают по звуку планта и войсу ещё до конца планта; они — на случай, когда не слышали.
- **Осталось (аудит 3–11):** T после планта стоят на бомбе (отсюда дефуз 40 % против 14 % у про), CT по ходу
  раунда не двигаются, экономика-заглушка, мало утилиты, первый фраг рано.
