# Промпты по чатам — Этап 2, мозг ботов (обновлено 09.10)

Дизайн мозга — `docs/BRAIN.md`, таблица чатов — его последний раздел.
Правила работы — `CLAUDE.md`. Одна строка = один новый чат.

**Как начинать каждый чат:** подключить репозиторий
`https://github.com/xa11mono/sim-cs2`, выбрать модель из таблицы, вставить
промпт шага целиком. Больше ничего не прикладывать: демки (94 шт.) лежат в
`data/demos/`.

Модели: **Opus 5.5** — где нужно проектировать и решать (что считать, какие
пороги, как устроить код). **Sonnet 5.5** — где задача уже расписана и её
надо аккуратно сделать. Fable 5.1 для этого проекта не нужен.

   tools/lineups.py со старыми жёсткими путями (/home/claude/demos/...,
