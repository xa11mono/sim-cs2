# Журнал решений (новые записи — сверху)

## 24.11.2026 — (v593) 3D: пол для наклона — строго, подложка, камера гранаты, повтор как вживую
- Пол у точки взгляда / впереди — `d3FloorAt` (ближайший к высоте бота в пределах `D3_FP_SLOPE` × расстояние, не дальше `D3_FP_DZMAX`); нет —
  горизонтально. Запасной навмеш давал верхний этаж. Числа — проектные.
- Повтор клатча — камера по живому виду (`D3.liveMode`): глаза → «за спиной» клатчера. Подложка — одна плоскость, сетка в шейдере.
- Камера гранаты — догон по времени (`D3_NADE_EYE/TGT`, проектные).

## 24.11.2026 — (v592) задержка эфира
- Экран отстаёт от игры на `BC.sec` = 1,5 с (проектное): кадр рисуется по записи раунда повтора (`RP.rec`) через одну подмену мира `rpSwap`
  (её же использует повтор клатча). Обсервер в подменённом мире получает `OBS_FUT` — убийства, которые игра уже сыграла, а экран ещё нет;
  счёт +`futBonus`, переключение даже из боя, если у другого убийство раньше на `futGap`. События показа (`SHOW_Q`, войс) несут тик и ждут
  экрана; киллфид — по времени экрана (`kfStage`). В закупке и разминке задержки нет (между раундами экран догоняет игру).
- Отметка владельца при задержке: `seenTick` (что было на экране) и `bcastDelay`; разбор отметки — от `seenTick`.

## 24.11.2026 — (v591) 3D: камеры глаз без среза, двусторонний «суп», рентген ближайших, анимации, обсервер
- Срез и стекло — только у камер сверху (`D3_EYE_CAMS`). Треугольники без замкнутого блока — двусторонние (vK + 3): сторону наружу данные
  не задают. Клипы «default» — косые (|nz| 0,12–0,97) и больше `D3_HIDE_AREA` = 20000 ед² (по снимкам обзора: косые листы исчезли, стены целы).
- Рентген — по просьбе владельца (показ, не знание бота): `D3_XR_R`, `D3_TAG_ENEMY`; силуэт — глубина GREATER после стен.
- Выстрел узнаём по новому трассеру (начало — у стрелка), игру не трогаем. Числа отдачи и толчка (`D3_KICK_MS`, `D3_PUNCH*`) — проектные.
- Обсервер: «холодный» бой (`hotCold`) отпускается к горячему / намного интереснее (`domK`, `domAdd`) — цифра почти не сдвинулась; остаток —
  мгновенные убийства, их без заглядывания вперёд не поймать.
