# Активная игра: что делают игроки в раунде (06.10)

Почему сейчас пассивно (v192): в одном выборе действия (`12_team.js`,
`ctChoose`/`tChoose`) есть только «встать в укрытие»: CT — укрытие в своём
районе; T — укрытие у точки сбора, укрытие на сайте, плант, пост-плант, сейв.
Никто никуда не идёт за инфой, не пикает, не пушит — поэтому и «опустевший
угол» никому не нужно закрывать (механизм есть, повода нет). Старые правила
проб/лёрка/пиков удалены, а целей вместо них не добавили.

Как добавлять: **не правилами под ситуацию, а вариантами действия в том же
одном выборе** (`actPick`). У каждого варианта — когда он выгоден (картина
команды, план IGL, роль, время раунда, число живых, деньги, гранаты) и чем
рискует. Бот сам выбирает лучший. Тимспик сообщает о выборе («иду за инфой на
донат», «нужен второй»), команда перестраивается (опустевший угол, просьбы —
уже есть).

## Варианты действия CT
| вариант | что делает | когда выгодно |
|---|---|---|
| держать по расстановке | угол/вход из плана IGL, укрытие | по умолчанию; мало инфы; экономия; меньшинство |
| ранний пик за инфой | в первые ~10–25 с выйти на линию подхода T (донат, кейв, мид, рамп), увидеть/выстрелить, сразу назад | есть флешка/смок или тиммейт для размена; T ещё не дошли (тайминги); роль агрессивная; раунд выгодный (фулл против эко/форса) |
| подпуш парой | «пушу X — иди со мной»: двое идут взять область (донат, кейв, мид), держат её, потом откат | инфы нет давно, ИГЛ хочет прочитать раунд; есть утилити; нас ≥ их |
| джиггл/инфо-пик | короткий выход-уход из-за угла, чтобы увидеть/услышать | стоит у угла, слышит шаги, но не видит |
| играть от ретейка | отдать сайт, стоять глубже, ждать выхода | стак T на сайте, нас меньше там |
| ротация | на колл/звук/гранаты выхода — на другой сайт | картина: выход на другом сайте; на своём пусто |
| смена позиции после контакта | пострелял/убил/засветился — на соседнее укрытие (off-angle) | всегда после контакта, если их ещё много рядом |
| отход | ранен, без размена, их больше | HP мало, рядом 2+ врагов |
| задержка утилити | молотов/смок во вход по звуку выхода | слышит выход, есть граната |
| уход от флешки | услышал/увидел бросок флешки — отвернуться (смотрит в стену), потом назад на угол | флешка летит в его сторону |

## Варианты действия T
| вариант | что делает | когда выгодно |
|---|---|---|
| контроль области (дефолт) | занять область (мид, верх, рамп, донат) с разменом, слушать | начало раунда, план IGL «дефолт» |
| проба | один-двое выходят за инфой (под флешку), смотрят, откатываются | инфы нет; хотим понять расстановку |
| лёрк | один тихо в другой части карты: инфа о ротациях, тайминг, флаг в спину | роль лёркер; выход идёт на другой сайт |
| выход на сайт | энтри первым, второй рядом на размен, саппорт кидает утилиту, AWP держит линию; бомба сзади | решение IGL: время, инфа, преимущество |
| фейк | шум и гранаты на одном сайте, выход на другой | план IGL; CT быстро ротируют |
| раш | быстрый выход в начале | эко/форс, читаем пассивных CT |
| пост-плант | разойтись, держать бомбу с дистанции и кроссфаером, тянуть время | после планта |
| смена позиции после контакта | как у CT | после контакта |
| сейв | беречь оружие | безнадёжно |

## Общее (обе стороны)
- Размен: второй рядом и готов разменять — у каждого «пушера» есть напарник.
- Перестройка по ходу: IGL меняет план по картине и времени (долго никого —
  один идёт проверить; стак — стянуть одного; минус — перестроить).
- Экономика влияет на риск: на эко — агрессия и стаки, на фулле — аккуратнее.

## Порядок (отдельные чаты)
1. Разметка точек: редактор на радаре, владелец правит точки (автоматические
   «укрытия» часто не в тему).
2. CT: ранний пик за инфой, подпуш парой, джиггл, смена позиции после
   контакта, уход от флешки.
3. T: контроль области, проба, лёрк, выход с ролями (энтри первым), фейк/раш.
4. Пост-плант с дистанции, отход, задержка утилити.
