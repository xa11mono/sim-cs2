# Правила этапа перестройки

Действуют вместе с `CLAUDE.md`; где строже — эти.

1. **Перестройка ≠ поведение.** Одна правка — либо перенос / чистка (игра не меняется), либо смена поведения. Никогда вместе.
2. **Бит в бит.** Перенос и чистка принимаются только если отпечаток игры совпал полностью:
   `bash tools/measure/fingerprint.sh sim.html <папка>` до и после, `diff -r` пусто. Не совпал — откат, искать, где ошибка. Число матчей
   отпечатка — как в `fingerprint.sh`; при сомнении — больше матчей, а не меньше.
3. **Маленькие шаги.** Один шаг — один перенос (функция, группа функций, поле), отпечаток, коммит. Без «перенёс полфайла, потом проверю».
4. **Ничего не теряем.** Каждое условие с пометкой «(vNNN) …» переезжает вместе с пометкой. Выбросить решение можно только по реестру
   решений с согласия владельца.
5. **Три уровня доказательств** (владелец 15.11):
   - *возможная причина* — в коде есть механизм, способный дать симптом;
   - *подтверждённая причина* — запись конкретного эпизода показывает, что сработал именно он;
   - *подтверждённое исправление* — повтор того же эпизода: ошибка ушла, похожие правильные сценарии сохранились, решение не
     перезаписано соседней системой.
   «Нашёл причину» говорить только на втором уровне, «исправил» — только на третьем.
6. **Воронка правки поведения** (до правки — оценка, после — замер): эпизодов симптома N → из них с подтверждённой причиной K
   (ожидаемый эффект ≤ K/N) → условие правки сработало в K' → действие действительно выполнено в K''. Теряется между K' и K'' —
   ищем, кто перезаписал или почему исполнитель не смог; K/N мало — не обещать сдвиг итоговой цифры.
7. **Один хозяин поля.** Перенесённому каналу ставится запрет: поле канала пишет только канал (проверка сборки). До переноса —
   нарушения выводятся предупреждениями.
8. **Карты — скриптом.** Кто пишет / читает поля, зависимости, порядок тика — генерируются, а не пишутся руками.
9. **Прогоны — на ПК**, объединять правки в один прогон (`CLAUDE.md` §8). Облако — отпечаток и короткие проверки.
10. **Отчёт владельцу простыми словами**: что сделано, отпечаток совпал / нет, было → стало (строк, функций, условий, файлов).
