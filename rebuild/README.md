# Перестройка sim-cs2 (с 15.11.2026)

Владелец 15.11: «код — каша; правка тянет за собой три поломки; хочу, чтобы всё было по полочкам, ничего друг друга не перекрывало,
ошибки легко находились — и боты остались такими же». Эта папка — всё для этапа перестройки. Новый чат по перестройке начинает отсюда.

**Цель.** Разложить проект и код по полочкам, **не меняя ботов**: каждый шаг перестройки проверяется отпечатком игры бит в бит
(те же матчи — те же действия до тика). Ни одно решение ботов не пишется заново: каждое из ~1430 решений в коде (пометки «(vNNN) …»)
либо переезжает на своё место, либо выбрасывается владельцем по списку реестра. Новый движок с нуля — нет (уже пробовали: боты были тупыми).

**Что в папке**
| файл | что |
|---|---|
| `PLAN.md` | фазы 0–4: что делаем, как проверяем, сколько сессий |
| `RULES.md` | правила этапа: бит в бит, не смешивать перестройку с поведением, три уровня доказательств, воронка правки |
| `FACTS.md` | замеры состояния на 15.11 (код, папки, документы) — «было» для сравнения |
| `DECISIONS.md` | что взято и что отклонено из предложений других нейросетей (15.11) и почему |
| `TOOLS.md` | инструменты, которые уже есть и нужны этапу (отпечаток, покрытие, ловец писателей, сторожа) |
| `PROGRESS.md` | журнал: что сделано в какой фазе, отпечаток совпал или нет, ссылки на коммиты |
| `OPEN_QUESTIONS.md` | вопросы владельцу, без ответа на которые фазу не начинать |
| `plan_page.html` | страница плана, опубликованная владельцу: https://claude.ai/artifact/6v5qwjjoKt8zQgNVdJNpS7 |

**Пока идёт перестройка:** код расстановок CT и тактик T — на паузе до своего канала (место — фаза 3, гранаты — фаза 3); разбор демок
и источников по дефолту A кода не трогает и может идти. Открытые пункты игры (рост «застрял» после В147, охота на последнего T) — в
