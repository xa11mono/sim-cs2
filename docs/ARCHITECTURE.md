## Карта файлов: файл → за что отвечает
Сборка `python3 src/build.py` склеивает `src/page.html` + `src/js/` по порядку
номеров + данные из `src/data/` в одну страницу `sim.html`. Порядок файлов —
порядок выполнения, переставлять куски нельзя (изменится игра).

## Как устроен исходник
С v177 игра — маленькие файлы (карта выше). `src/build.py` склеивает их,
вставляет данные из `src/data/` на места меток `@@DATA:…@@` / `@@PNG:…@@` и
генерируемое (список переменных для перемотки, пункты PRINCIPLES, модуль
`src/marks.js`). Склейка дала ту же страницу, что один файл `game.html` (бит
в бит). Инструмент отметок (`src/marks.js`) мозг ботов не трогает; снимок всей
игры — `mkSnapshot`/`mkRestore`, в файл — `mkPack`/`mkUnpack`, открыть
отметку — `mkOpenSnap` (на странице) и `tools/mark_open.js` (без экрана).
История: до v168 — orig.html + 24 патча, v168–v176 — один `src/game.html`.

## Из чего состоит (кратко)
- **Карта:** радар Ancient, стены нарисованы вручную (`MANUAL_WALLS`, ~540
  отрезков), навмеш для путей, ~60 именованных зон (`ZONEMAP`, `BZ`).
- **Знание о врагах (с v169 — одна картина на команду):**
  - вход — только общий канал: увидел — сразу (как радар), услышал/сказал —
    когда это договорили в тимспике (`voiceTick` → `intelPush`). Журнал канала
    `teamIntel[team].sig` — лента событий (смерти, фраги, гранаты, звуки);
  - картина (с v196, В15 — без вероятности по зонам): **инфа** — последнее
    наблюдение по каждому врагу `beliefLast` (видел / слышал / колл, с пометкой
    «проверили — пусто»; звук «их трое» — трое разных врагов, `soundWho` — кому
    приписать по тому, кто успевал туда добежать); свежесть инфы `infoW` — 1 до 4 с,
    к 20 с — 0; **куда враг мог успеть** — `REACH` (самый ранний тик в каждой зоне:
    от спавна или от места инфы, по времени бега); **закрыто своими** — зону видят
    свои и там пусто → закрыта, через неё путь не идёт (`knowTick` → `reachStep`).
    Удалено (v196): `belief` (вероятность каждого врага по зонам и её
    «расплывание» к сайтам), `beliefMass`/`beliefCount`/`beliefZoneKnown`/
    `beliefZoneFresh`/`beliefMassNear`/`beliefClearAt`, «потенциалы» целей врага
    `BZ.potT/potCT`, разнесение «убил невидимый» по зонам, `BAL.reachBlock`.
    Читают через `infoZone` (инфа в зоне), `infoCount` (сколько по инфе в районе —
    колл), `infoNear`, `picKnown` (кому из наблюдений ещё верить — до 10 с),
    `picRecent` (свежие наблюдения), `picNear` / `intelEstimate` (сколько рядом),
    `picOutnumbered` (у точки их на 2+ больше, чем нас);
  - у бота лично — только его органы чувств: что сам видел (`lastIntel`) и
    слышал (`ears`/`heardSound`). Тиммейты туда больше не пишут;
  - колл CT (`ct.call`) — одно место, считает по картине;
  - события (смерти, фраги, звуки по порядку) читаются только через
    `picEvents` — «ленту событий» картины;
  - памяти о сопернике между раундами нет (с v182 удалена вся: `MEMORY`, копия
    между матчами `OPP`, тайм-ауты, выводы перерыва, чтение темпа и стаков,
    привычки CT, где умирали T, куда кидали гранаты). Вернётся позже одним местом
    как часть картины команды. Чтение внутри раунда осталось: закуп врага по
    увиденному оружию (`buyRead`), выход T по гранатам у сайта (`tacRead`),
    ротация CT на слух (`rotRead`) — это восприятие, а не память.
- **Восприятие (с v183, К11) — бот узнаёт о врагах только так, как игрок в CS2:**
  - **уши — одно место `makeSound` (14_movement.js, таблица `SOUND`):** шаги
    бегом (шифт не слышно, вода — слышно), стрельба (глушитель тише), «по мне
    стреляют» (только тому, в кого стреляли), перезарядка (по звуку — каким
    оружием, значит, сколько длится), зум AWP, бросок гранаты, разрыв гранаты
    (слышно или видно), плант, дефуз (начало `defuse`, продолжение `defusing`),
    подбор оружия; `nadefly` — видел полёт гранаты, но не бросавшего → примерно
    откуда кинули. Направление ±6° (через стену ±17°), дистанция ±15% (±30%).
    В услышанном нет ника. У бота — список звуков за 3 с `b.ears`, сколько
    разных источников — `earsSources`; `b.heardSound` — последний. Прыжков в
    игре нет — их звука тоже;
  - **в картину команды** звук идёт через тимспик (`teamInfoTick` → блокнот
    бота → фраза в эфире, см. «Тимспик»); кому из врагов его приписать — `soundWho`: тому, кто по
    картине вероятнее всего там (n источников — n разных врагов). Плант
    («плантят на A») команда узнаёт тоже из колла (`plantHeard`); разрыв гранаты
    врага — `nadeSeen` для чтения выхода;
  - **глаза:** «вижу» — ник и оружие в руках (`buyReadSee` по увиденному);
    бомба у кого / на земле — только если видели; где смок/молотов — видно всем;
  - **киллфид** (`feedKill` → `killfeedRead`): закуп по оружию убийцы; кто с
    AWP. Роль врага по нику — `FOE.roles` (только этот матч): CT — где стоял в
    начале раунда (A/B/мид), T — AWP, первым на сайте (энтри), один вдали от
    своих (люркер); `foeRole` — роль, если видели так 2+ раза. Колл «минус» несёт
    эту догадку, а не настоящую роль;
  - **деньги врага** — подсчёт по открытому (`FOE.money/gun`): $800 в начале
