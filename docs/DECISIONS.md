# Журнал решений (новые записи — сверху)

## 10.10.2026 — Одно знание: память команды только из глаз, радара и войса (v242, по предложению, владелец — «да»)

**Почему.** После v240–v241 у решений было два источника «где враг»: знание (гипотезы + войс, честное) и память команды
v166 (`commSend` → `teamIntel` / `beliefLast` / `LKP`), где у каждого звука был известен шумящий враг и он сразу (через
придуманную задержку очереди) уходил всей команде.

**Что сделано.** `commSend` — только радар (кого видит свой), очереди нет. Звуки команде — только из договорённых фраз
войса (`teamHeardToIntel`: зона и что, `id "?"`). «Плант слышали» — из фразы «ставят B!», а не сразу. Звук броска гранаты
команде не передаётся; «видел бросок» — только в поле зрения. Последняя инфа по врагу (`beliefLast`, `LKP`) от звука — из
знания тиммейтов: гипотеза «слышал здесь» с весом ≥ 0,35 (порог v166). Остались как в v166: смерть своего (место смерти
и примерное направление выстрела), размен по ней.

**Цифры (6 матчей; про / v166 / v241 / v242).** CT выиграли 51,5 / 48,7 / 41,6 / 55,5 %; смертей T до 45 с 1,49 / 1,83 /
1,78 / 1,96; CT у сайта в момент планта 1,01 / 0,54 / 0,51 / 0,36 (хуже: про плант CT узнают позже — из войса);
CT с других мест идут к стаку за 5 с 19,0 / 18,1 / 18,7 / 14,1 % (хуже); размен 17,4 / 11,6 / 12,7 / 12,8 %.

## 10.10.2026 — Карта, 3D-видимость, войс, киллфид и табло из переделки (v241, просьба владельца)

**Почему.** Владелец: «возвращаем прострелы, укрытия, стенки, навесы, высоты — все механики; тимспик, связанный с инфой;
киллфид и иконки».

**Что сделано.** Стены — `walls.json` переделки (правки владельца), `applyWalls`; старый редактор стен v166 (localStorage,
«рисовать стены», «выравнивание стен») удалён — вместо него «правка карты» (стены / высоты / укрытия / прострелы, Ctrl+Z,
сохранение в базу страницы), слои «высоты», «укрытия», «прострелы», «кто кого видит». Видимость — одно место, 3D
(`visLine`/`visParts`; `hasLOS` через неё): стены, укрытия, пол/уступы, крыши (`VIS_CEIL_H` — проектное число переделки).
Бой: видно голову / тело, стреляют в видимое, пуля в закрытую часть модели — в укрытие; заплатка `BAL.hbCover` удалена.
Прострелы — разметка + формула CS2, стрелять сквозь стены боты не умеют; прыжков на уступы нет. Войс — канал переделки
(`team*` → `knowCall`), переходник `knowVoice` удалён; память команды v166 (`commSend`/`intelPush`, с «кто» у звука) пока
своя. Киллфид с иконками и ассистом, табло и панели игроков — из переделки.

**Цифры (6 матчей; про / v166 / v240 / v241).** CT выиграли 51,5 / 48,7 / 30,4 / 41,6 %; смертей CT до 45 с 1,29 / 1,87 /
2,16 / 1,77; размен за 3 с 17,4 / 11,6 / 11,3 / 12,7 %; первый фраг 24,7 / 20,5 / 20,5 / 21,3 с; гранат CT 9,9 / 9,5 / 7,5 /
8,5; длительность раунда 82,6 / 77,3 / 80,4 / 86,4 с; последний против 2+ живёт 10,2 / 17,0 / 16,0 / 24,5 с (хуже).

## 10.10.2026 — Знание о врагах из переделки вместо растекания весов v166 (v240, просьба владельца)

**Почему.** Владелец: «сохрани систему весов и поменяй её на восприятие и гипотезы; добавь позиции из демок». В v166 карта
«где может быть враг» растекалась по зонам сама (`beliefTick`, `m=0.12` к сайтам) — отсюда «вес соседней зоны растёт,
бот отворачивается».

**Что сделано.** Веса v166 — в ветке `v166-weights`. В `game.html` — знание из `rebuild-v238/09_knowledge.js` (гипотезы
held / moved / moved_unknown, числа `KNOW` — проектные числа переделки): глаза + радар (кого видит любой живой свой),
уши `hearReal` (все настоящие звуки v166), войс v166 (`intelPush` → `knowVoice`, только зона), киллфид (`knowKill`),
«проверил — пусто» (`knowClearZone`, свой взгляд — `knowLook`, теперь и для веток «ушёл туда»). `beliefTick` больше не
растекает: карта команды = среднее гипотез живых тиммейтов (moved — где бегущий был бы сейчас по таймингу маршрута;
moved_unknown — по типичным местам врага, проверенные — ноль; убийца, которого не видели, — по зонам, откуда простреливается
место смерти). Убраны: растекание, `beliefSet`, `beliefClearAt`, потенциалы `potT/potCT`. Тайминги `reach*` — как в v166.
Места про из 88 демок (`KNOW_POSITIONS`) — варианты в `holdCands`, выбирает та же оценка v166.

**Цифры (6 матчей, до двух последних правок).** Отворот стоя без инфы (матчи 3, 7): 1,44 → 1,10 в минуту. Взгляд
туда-обратно 1,14 → 0,99 (про 0,8). **Хуже: CT выиграли 48,7 → 30,4 % (про 51,5)**, смертей CT до 45 с 1,87 → 2,16,
гранат CT 9,5 → 7,5. Найдено две причины и исправлено (без нового прогона): убийцу «ставили» на место смерти своего, а не
туда, откуда простреливается; ветка «ушёл туда» не гасла, когда CT смотрел на её зону и там пусто.
