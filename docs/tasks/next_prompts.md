# Промпты для новых чатов (20.10.2026)

Один шаг — один чат. Порядок — раздел «Порядок» ниже (`docs/ROADMAP.md`). В каждом чате действуют `CLAUDE.md` (подгружается сам) и
`docs/tasks/work_rules.md`. Общее для всех шагов:
- сначала «Понял так…» + план одним сообщением, ждать «да»;
- проверка правки, меняющей игру: база и правка на одних и тех же 8 матчах на каждую карту (`--matches=3,7,11,13,17,19,23,29`, по
  одному прогону в фоне), `check.py --base=…`; меньше различимого — «шум»;
- в конце: ARCHITECTURE (если менялось устройство), запись в DECISIONS, пункт PRINCIPLES «исправлено в vNNN, ждёт проверки»,
  коммит, публикация обеих страниц (Ancient, Mirage).
